Оригинальные материалы, использованные для уточнения методики libtr. PDF и HTML
сохранены без содержательной переработки. HTML — снимок одной страницы, без
зеркалирования внешних стилей, скриптов и связанных страниц. Это справочные
материалы авторов, а не нормативные документы или собственные исходники libtr.
Версия ISTQB указана в документе; HTML зафиксирован датой получения.

## Как используются

- ISTQB: требования как основание проверок; классы входов, границы, решения и
  переходы; различие проверки компонента и его взаимодействия с другими.
- Cucumber: понятный пример с предпосылкой, событием и наблюдаемым результатом.
  Синтаксис Gherkin и его исполнитель для libtr не обязательны.
- MathWorks: явный численный допуск и диагностика отличий; выбор конкретного
  тестового API не является требованием к реализации.
