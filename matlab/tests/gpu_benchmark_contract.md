# Предварительное измерение GPU

@CRITERION GPU-TIME-001: одинаковые double входы CPU/GPU; формулы
atan2(y,x), atan2(z,hypot(x,y)) из физического генератора. Максимальная
абсолютная разность <=1e-12 рад (критерий эксперимента, не изменение паспорта).
N=1000/10000/100000/1000000 — точки измерения, не ограничения продукта.
После прогрева семь повторов, чередование порядка CPU/GPU. Сохранять все
времена и медианы: CPU, GPU с передачей входов/выходов, GPU на готовых входах.
wait до/после замера GPU исключает асинхронный недомер. RNG восстанавливается.
Ускорение не является условием PASS: check проверяет корректность эксперимента.
Не измеряются RNG, оцениватели, графики и полный цикл ТИС. Производство не меняется.
