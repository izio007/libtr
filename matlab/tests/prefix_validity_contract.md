# RESULT-01: допуск к накопленному RMSE

@CRITERION PREFIX-VALID-001: четвёртый необязательный аргумент
service_cumulative_rmse — логическая маска допуска размерности statuses.
Она может только исключать результаты; статус неуспеха или неконечный выход
не становится допустимым. Трёхаргументный интерфейс сохраняет прежнюю семантику.
Неверные тип и размер маски отклоняются. Исходные данные не изменяются.

@CRITERION PREFIX-VALID-002: статический сценарий использует r.valid для облака,
счётчика отказов и накопленной кривой. Режим B проверяется по сохранённым MAT
прямой формулой для каждого префикса. Неверный конечный результат исключается
из суммы и знаменателя; в графической кривой на его позиции остаётся NaN.
Исторические MAT без valid не переаттестовываются; их адаптация отдельная задача.
