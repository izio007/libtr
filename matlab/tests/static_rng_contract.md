# Явный контекст статического сценария (ENG-03)

@CRITERION STATIC-RNG-001: generate_tis_static_passport создаёт локальный
engine_rng_init по прежнему seed и передаёт возвращаемый контекст следующей
ячейке. Глобальный RNG не используется для наблюдений и не меняется.

@CRITERION STATIC-RNG-002: для repeats=[1 2], runs=2 сохранённые alpha/beta
побитово совпадают с прежней последовательностью rng(seed,'twister')/randn.
MAT initial/next образуют непрерывную цепочку. Проверка не доказывает
межверсионную воспроизводимость или статистическую независимость seeds.

Графические команды, параметры сценария и математические ядра не меняются.
Расчётные PNG разрешены; экспорт HTML/Live Editor не выполняется.
