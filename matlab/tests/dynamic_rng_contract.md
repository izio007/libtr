# ENG-03: контекст динамического сценария

@CRITERION DYNAMIC-RNG-001: сценарий создаёт engine_rng_init по seed конфигурации
и передаёт next последовательно между всеми ячейками (сначала точки, затем число
постов). Глобальный RNG вызывающего кода неизменен.

@CRITERION DYNAMIC-RNG-002: в сокращённом сценарии (две точки, две реализации,
вся штатная сетка числа постов) alpha/beta побитово совпадают с прежним
rng(seed,'twister')/randn; MAT initial/next образуют непрерывную цепочку.
Четыре PNG читаются. Это регрессия, не эталонная приёмка или доказательство
статистической независимости. Оформление, параметры и ядра не изменяются.
