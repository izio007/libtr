# Явный RNG физического движка

Контекст — value struct версии 1: mt19937ar, Ziggurat, uint32 State.
Локальный RandStream создаётся внутри вызова и наружу не передаётся.
Входной контекст неизменен; выходной явно передаётся в следующий вызов.
Порядок выборок: весь массив азимута, затем весь массив угла места.
Разбиение пакета не обязано сохранять прежнее чередование каналов.

@CRITERION ENGINE-RNG-001: global rng не меняется при успехе или отказе;
копирование и MAT-сохранение контекста воспроизводят продолжение.
@CRITERION ENGINE-RNG-002: перемежение экземпляров не влияет на их выходы;
состояния не содержат handle. Это изоляция, не доказательство статистической
независимости последовательностей разных seeds и не переносимость между версиями MATLAB.
@CRITERION ENGINE-RNG-003: на общих seed массивы совпадают с независимым
локальным RandStream; прежние тестовые сценарии сохраняют последовательность
через test_sample_bearings. Глобальная политика legacy остаётся только в tests.
API service_sample_bearings требует явного шестого аргумента; внешние потребители
должны перейти на него. service_add_noise_ox принимает также seed без изменения rng.
