# Расчётные функции и испытательная среда

Чистые вычислительные ядра находятся в matlab/function/. Физические генераторы
service_sample_bearings и service_add_noise_ox находятся в matlab/engine/;
параметры передаёт вызывающий код. Сценарии, метрики и независимые реперы —
в matlab/tests/ и support/. Дополнительный перенос ради регламента не нужен.

@CRITERION MATLAB-LAYOUT-001: производственный код не зависит от tests и tools.
RNG допустим в стохастической модели engine с явным контекстом;
чистые функции не вводят скрытого случайного состояния.

@CRITERION MATLAB-LAYOUT-002: проверки путей, независимости production,
графических опытов и сценария фильтра можно вызывать непосредственно из MATLAB.
Конкретный способ запуска не является свойством математического результата.

@CRITERION MATLAB-LAYOUT-003: запуск не останавливает чужие процессы,
не очищает рабочее пространство пользователя и не требует отдельного сервера.
Имеющийся TCP-вход — необязательный инфраструктурный инструмент.

@CRITERION MATLAB-LAYOUT-004: испытательная ячейка принимает явный RNG-контекст
и возвращает его продолжение. Явный режим не меняет глобальный RNG;
перемежение независимых ячеек не меняет результатов. Прежний шестипараметрический
вызов остаётся адаптером старых сценариев в tests.
