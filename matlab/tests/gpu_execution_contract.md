# GPU-исполнение массовых испытаний

Статус: технические условия отдельной будущей GPU-задачи; реализация ещё
не выполнена. Обычные проверки и запуск MATLAB Desktop не требуют GPU.
Массовый GPU-профиль запускается по выбранной задаче, без общего Code Freeze
и автоматического выпуска отчётности. Микробенчмарк геометрии не подтверждает
готовность полного сценария.

## Декомпозиция исполнения

- Параллелить независимые реализации наблюдений, сценарии и экземпляры
  оценивателей; такты одного алгоритма с памятью сохраняют причинный порядок.
- Данные и промежуточные расчёты удерживать на GPU между стадиями; передавать
  результаты для сохранения и представления явно, вне внутренних скалярных циклов.
- Разбивать пакет по доступной памяти без потери, повторения или перестановки
  идентификаторов реализаций. Размер блока не меняет смысл сценария.
- Сохранить double, скалярный CPU-контракт и независимые контрольные проверки.
  Подмена GPU CPU-расчётом в явно выбранном GPU-режиме запрещена.
- RNG-контекст, источник наблюдений и порядок обработки фиксировать явно;
  CPU/GPU сравнивать на общих сохранённых наблюдениях, а не только общем seed.
- Диспетчеризация, файловый обмен, сборка и представление результатов остаются
  инфраструктурными обязанностями. Требование GPU относится к численной нагрузке,
  а не обещает исполнение Git, компилятора или экспортёра документов на видеокарте.

## Численные и ресурсные условия выбранного GPU-профиля

@CRITERION GPU-EXEC-001: выбранный GPU-профиль отклоняет недоступный GPU и
неподдерживаемую расчётную стадию; инъекция отказа не вызывает CPU-fallback.
@CRITERION GPU-EXEC-002: параллельный пакет и разные размеры блоков на общих
наблюдениях сохраняют статусы, valid, идентификаторы и результаты в допусках
математического контракта; CPU-репер используется только для проверки.
@CRITERION GPU-EXEC-003: независимые контексты не смешиваются, последовательный
алгоритм сохраняет порядок времени; ошибка и отмена освобождают ресурсы задания,
не затрагивая чужие процессы и сеансы MATLAB.
@CRITERION GPU-EXEC-004: отчёт фиксирует GPU, double, размер пакета/блоков,
исполнителя каждой стадии, синхронизированные времена расчёта и передачи,
полное время сценария и сравнение с CPU. Ускорение не предполагается заранее.

Расчётная отчётность использует результаты того же запуска, не пересчитывает
их скрытно на CPU. Представление в другом формате создаётся отдельно по задаче пользователя.
