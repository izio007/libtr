Математическая модель логического супервизора автономного принятия решений ПРГСН в трехмерном пространстве

Критерии подтверждения и прерывания целевой задачи на основе декартовых оценок КЛО и ковариационного анализа

Функционирование автономного логического супервизора на частоте \(100\) Гц заключается в непрерывной обработке оценок трехмерного вектора координат источника излучения \(U_k = [X_ц, Y_ц, Z_ц]^T\), среднегеометрического пространственного промаха \(R_{miss, k}\) и декартовой ковариационной матрицы ошибок триангуляции \(K_\lambda(k)\). На основе этих данных формируется булево решающее правило прерывания текущей задачи наведения \(\text{Trigger}_{ABORT}\) и переключения внешней САУ на следующую точку полетного задания.

1. Расчет динамических и геометрических параметров траектории

На каждом дискретном такте времени \(t_k\) вычисляется модуль вектора полной скорости летательного аппарата:

\[V_{mod, k} = \sqrt{V_{x, k}^2 + V_{y, k}^2 + V_{z, k}^2}\]

Вектор относительной скорости сближения в декартовой системе координат определяется через дифференцирование дальности (промаха), где в квазипрямолинейном приближении скорость сближения \(\dot{R}_{miss, k}\) полагается равной \(-V_{mod, k}\). Оставшееся время до расчетной точки динамической встречи (Time-to-Go) имеет вид:

\[T_{go, k} = \frac{R_{miss, k}}{V_{mod, k}}\]

Текущий радиальный размер пространственной зоны неопределенности местоопределения (облако ошибок триангуляции по доверительному уровню \(2\sigma\)) рассчитывается на основе спектрального радиуса матрицы \(K_\lambda\) через её максимальное собственное значение, аппроксимируемое диагональными элементами:

\[R_{error, k} = 2 \cdot \sqrt{\max\left(\operatorname{diag}\left(K_\lambda(k)\right)\right)}\]

2. Математические условия автономной отмены целевой задачи

Решение об отмене полёта на текущий источник излучения принимается при истинности обобщенного логического предиката, объединяющего три физических критерия эффективности:

\[\text{Trigger}_{ABORT} = \mathcal{C}_{time} \quad \cup \quad \mathcal{C}_{decoy} \quad \cup \quad \mathcal{C}_{blink}\]

2.1. Критерий деградации временного резерва (\(\mathcal{C}_{time}\))

Условие описывает ситуацию, при которой оставшийся кинематический ресурс времени сближения \(T_{go, k}\) меньше минимально необходимого времени \(T_{maneuver}\), требуемого САУ для отработки динамического маневра совмещения, при этом текущий размер облака ошибок \(R_{error, k}\) превышает радиус гарантированного поражения цели \(R_{lethal}\):

\[\mathcal{C}_{time} = \begin{cases} 1, & \text{при } T_{go, k} \le T_{maneuver} \quad \cap \quad R_{error, k} > R_{lethal} \\\\ 0, & \text{в противном случае} \end{cases}\]

2.2. Критерий пространственной нестабильности оценок при отстреле ловушек (\(\mathcal{C}_{decoy}\))

При применении источником излучения средств пространственно-распределенного противодействия (отстрел ложных угловых целей, ловушек) оценки координат \(U_k\) теряют точку сходимости. Математическая модель фиксирует этот процесс через вычисление пространственной дисперсии (разброса) вектора целей в скользящем окне памяти глубиной \(M_t\) относительно его текущего среднего математического ожидания \(\bar{U}_k\):

\[\bar{U}_k = \frac{1}{M_t} \sum_{j=0}^{M_t-1} U_{k-j}\]
\[D_{coord, k} = \frac{1}{M_t} \sum_{j=0}^{M_t-1} \|U_{k-j} - \bar{U}_k\|^2\]
\[\mathcal{C}_{decoy} = \begin{cases} 1, & \text{при } D_{coord, k} > D_{threshold} \quad \cap \quad \|U_k\| > 0 \\\\ 0, & \text{в противном случае} \end{cases}\]

2.3. Критерий скрытности и мерцания излучения (\(\mathcal{C}_{blink}\))

При переходе РЛС цели в прерывистый режим работы (мерцание) контроллер накапливает интегральное время активного приема сигналов \(T_{active}\) и время нахождения системы в режиме слепой экстраполяции \(T_{silence}\). Информационный коэффициент достаточности \(\eta_k\) сопоставляет эти параметры:

\[\eta_k = \frac{T_{active}(t_k)}{T_{silence}(t_k) + \nu}\]
\[\mathcal{C}_{blink} = \begin{cases} 1, & \text{при } \eta_k < \eta_{min} \quad \cap \quad R_{error, k} > R_{lethal} \quad \cap \quad t_k > t_{init} \\\\ 0, & \text{в противном случае} \end{cases}\]

где \(\nu \to 0\) — малый параметр против деления на ноль, а \(t_{init}\) — время начального раскрытия измерительной базы.

3. Логика подтверждения и сброса задачи

Результирующий статус выполнения боевого задания формируется на основе мгновенного значения логического триггера отмены:

\[\text{Mission\_Status} = \begin{cases} \text{MISSION\_ABORTED}, & \text{при } \text{Trigger}_{ABORT} == 1 \\\\ \text{MISSION\_CONFIRMED}, & \text{при } \text{Trigger}_{ABORT} == 0 \end{cases}\]

При переходе в состояние \(\text{MISSION\_ABORTED}\) контроллер ПРГСН принудительно обнуляет регистры текущей цели (\(U_k = [0,0,0]^T\)), очищает измерительные буферы предыстории КЛО и выдает команду на внешнюю САУ для изменения траектории полета в направлении следующей маршрутной точки.
