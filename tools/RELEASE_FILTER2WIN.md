# Упаковка filter2win

Из корня репозитория:

~~~bash
python3 tools/package_filter2win.py --version 0.3.1 --output Release
~~~

На Windows можно использовать python вместо python3.

Результат — Release/filter2win-0.3.1.zip. Внутри находятся исходники MATLAB,
конфигурации, пять обычных тестов, их вспомогательные функции, Markdown-паспорта,
VERSION и README с примером использования.

Упаковка копирует исходные файлы без изменения содержимого. Она не запускает
MATLAB, тесты, службы, экспорт PDF/HTML/Live Editor или процедуру приёмки.
Повторная команда не перезаписывает существующий ZIP: выберите другую версию
или другой выходной каталог.

Документацию в других форматах создавайте отдельно, когда она нужна.
