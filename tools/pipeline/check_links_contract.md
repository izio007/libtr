# Адресация проверок — первый срез

@CRITERION CHECK-LINK-007: декларация matmul3 включает локальные Python-модули,
явно импортируемые объявленными Python-входами. Регрессия обнаруживает исключение
check_mapping.py. Это ограниченный статический контроль соседних .py-модулей,
не доказательство полноты динамических импортов, пакетов или MATLAB-зависимостей.

@CRITERION CHECK-LINK-006: предварительная и последующая проверки используют
общий разбор таблицы и определений. Пустая таблица, неверные типы полей,
повторные имена и отсутствующий/неоднозначный критерий отклоняются.
Политика путей и проверка происхождения байтов остаются у вызывающей стороны.

@CRITERION CHECK-LINK-001: явная таблица связывает имя unit-теста с ID критерия,
путём определения и исходником теста. ID имеет ровно одно определение
@CRITERION в указанном файле; дубликаты имён и неизвестные состояния отклоняются.
@CRITERION CHECK-LINK-002: unit_results.json читается только после сверки всех
хешей реестра артефактов. Повторные имена результатов отклоняются. Отсутствующий
запуск отражается NOT_RUN; немаппированные записи не пропадают из отчёта.
@CRITERION CHECK-LINK-003: исторический исход теста хранится отдельно от
состояния критерия. Новая таблица не переносит PASS старого запуска на новую
редакцию критерия: criterion_status=NOT_RUN, applicability=UNCONFIRMED.
Сохраняются хеши таблицы, определения, теста, реестра и конкретных байтов результатов.
Это навигационная связь, не подтверждение исполнения текущего исходника.

@CRITERION CHECK-LINK-004: необязательный --snapshot указывает каталог снимка.
Хеш его manifest.json должен совпадать с реестром; байты нужных сохранённых
входов сверяются с манифестом. Для таблицы, определения и теста отдельно
выдаются MATCH, CHANGED или NOT_CAPTURED относительно текущих прочитанных байтов.
Без снимка — UNCONFIRMED. MATCH не подтверждает загруженный MATLAB-код и не
меняет criterion_status. Повреждённый снимок или дубликаты его путей отклоняются.

@CRITERION CHECK-LINK-005: поле check_mapping в декларации входов включает
предпроверку для адресного unit-запуска. Таблица, определения и исходники
читаются из снимка и проверяются по хешам. Выбранный тест должен иметь ровно
одну запись, критерий — ровно одно определение. Ошибка блокирует submit;
attempt.json сохраняет preflight=FAILED и server_response=null. Без поля
предпроверка NOT_RUN (обратная совместимость). PASS предпроверки — целостность
связей, не доказательство математического утверждения.
