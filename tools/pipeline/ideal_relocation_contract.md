# Перенос адаптера идеальных наблюдений

Задача 4 need_work.md. service_ideal_mock_position — испытательный адаптер
геометрии к mock_position, а не независимый репер. Целевой каталог matlab/tests/support/.

@CRITERION IDEAL-MOVE-001: SHA-256 до/после совпадает, старый файл отсутствует.
@CRITERION IDEAL-MOVE-002: unit_test_engine_isolation проходит до/после;
адаптер недоступен на production path и однозначно доступен из matlab/tests/support/.
@CRITERION IDEAL-MOVE-003: на чистом пути без support известная цель [2;3;4]
для четырёх постов восстанавливается с абсолютной ошибкой менее 1e-10 м;
недостаточная сеть возвращает статус 1 и NaN.

Порог репера относится только к указанной безошумной геометрии.
Перенос не меняет математику mock и не заменяет эталонную приёмку 30/450 км.
Исторические результаты относятся к прежним байтам контрактов; изменение целевого пути не переаттестовывает их. Текущая архитектура — .clinerules.
