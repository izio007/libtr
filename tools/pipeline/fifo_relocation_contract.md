# Перенос FIFO без изменения реализации

Основание: .clinerules, need_work.md задача 4. Четыре fifo_*.m переносятся
из matlab/ в matlab/function/ с сохранением байтов, сигнатур и int32.
Отдельный математический паспорт и потребители при поиске не найдены.
Ниже ограниченный контракт регрессии по комментариям существующего API,
а не утверждение пригодности для всех возможных входов.

Область теста: положительная целая capacity, int32-вектор ровно этой длины,
int32 count от 0 до capacity; int32 значения и индексы. Ориентация сохраняется.
Очередь хранит старейший элемент первым; push вытесняет старейший при заполнении;
delete_at удаляет допустимый индекс и обнуляет освободившийся хвост;
недопустимый индекс ничего не меняет; clear обнуляет буфер и count;
peek возвращает последний элемент либо false/int32(-1) при пустой очереди.
Поведение при неверном count, capacity=0 и несогласованном буфере не принимается
этим тестом: в существующих функциях нет общего валидатора таких входов.

@CRITERION MOVE-FIFO-001: сравнить с независимой моделью динамического списка
для capacity=1,2,5, обеих ориентаций, пустой/полной очереди, вытеснения,
удаления начала/середины/конца и неверного индекса. До и после переноса PASS.
@CRITERION MOVE-FIFO-002: SHA-256 каждого файла сохранён; старые файлы отсутствуют;
чистый production path разрешает единственный экземпляр каждой функции.

Графики и экспорт не относятся к этому локальному тесту; приёмка комплекса
и устранение пробела полного FIFO-паспорта не заявляются.
Исторические результаты относятся к прежним байтам контрактов; изменение целевого пути не переаттестовывает их. Текущая архитектура — .clinerules.
