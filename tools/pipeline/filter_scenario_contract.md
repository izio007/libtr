# Явный сценарий filter2win

@CRITERION FILTER-SCENARIO-001: инструментарий matlab/tests/support/filter2win_scenario.m
возвращает время, истину, измерения, выходы и мощность окна без графики,
файлового I/O и eval. RNG задаёт вызывающий код.
@CRITERION FILTER-SCENARIO-002: при seed 1729 все пять массивов совпадают
с сохранённым до рефакторинга MAT через isequaln. Производственное ядро неизменно.
@CRITERION FILTER-SCENARIO-003: генератор использует функцию напрямую;
unit_test_filter_plot_path проходит, строки оформления графиков не меняются.

Контрольный снимок этой миграции: runtime/filter_scenario_baseline_20260930/.
Он производный, не новый математический эталон. Постоянные проверки сценария:
размеры, временная сетка, пропуски и повторяемость при одинаковом RNG.
