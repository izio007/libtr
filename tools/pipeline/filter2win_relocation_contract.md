# Перенос filter2win

Основания: .clinerules, docs/filter2win_theory.md, задача 4 need_work.md.
Перенести matlab/filter2win.m в matlab/function/ без изменения байтов.
Скалярный интерфейс и явное состояние сохраняются.

@CRITERION MOVE-FILTER-001: SHA-256 до/после совпадает; старый файл отсутствует;
единственное разрешение функции на чистом пути matlab/function/.
@CRITERION MOVE-FILTER-002: unit_test_filter2win проходит до/после;
после проходит unit_test_production_isolation.
@CRITERION MOVE-FILTER-003: независимая последовательность 0,2 даёт среднее 1;
два экземпляра состояния не влияют друг на друга; повтор времени возвращает
status=1 без изменения состояния; граница удержания включающая, затем выход NaN.

Перенос не меняет паспорт и не включает экспорт альтернативных документов.
Полная валидация произвольно повреждённого FILTER_STATE не заявляется:
паспорт требует возвращать созданное ядром состояние без ручной правки.
Исторические результаты относятся к прежним байтам контрактов; изменение целевого пути не переаттестовывает их. Текущая архитектура — .clinerules.
