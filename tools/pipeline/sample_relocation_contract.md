# Перенос синтетики пеленгов

Задача 4 need_work.md; .clinerules: физическая модель в matlab/engine/.
service_sample_bearings переносится из matlab/tests/support/ без изменения байтов.
service_add_noise_ox также находится в engine; его rng(seed) требует отдельного контракта.

@CRITERION SAMPLE-MOVE-001: одинаковые SHA-256, отсутствие старого файла,
единственное разрешение из matlab/engine/; функция доступна на чистом производственном пути.
@CRITERION SAMPLE-MOVE-002: unit_test_graphical_experiments проходит до/после.
@CRITERION SAMPLE-MOVE-003: для осевых постов и цели 0 идеальные азимуты
равны [0;pi/2], углы места нулевые. С одинаковым RNG шумовые массивы
соответствуют двум последовательным randn, размеры [4,5], variance=sigma^2.
@CRITERION SAMPLE-MOVE-004: потребитель tis_experiment_cell выполняется на малом
пакете; MAT сохраняет общие наблюдения для четырёх методов. Это smoke-check,
не доказательство статистической точности или эталонная приёмка.
Исторические результаты относятся к прежним байтам контрактов; изменение целевого пути не переаттестовывает их. Текущая архитектура — .clinerules.
