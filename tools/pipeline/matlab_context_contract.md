# Контекст MATLAB: Desktop и выделенный сервер

`matlab/run_tests.m` и общий `matlab/tests/run_unit_tests.m` работают в текущей
сессии. Общий исполнитель сохраняет и восстанавливает cwd, path и RNG вокруг
каждого unit-теста; перед тестом задаёт seed 1729. Несуществующие каталоги
удаляются из сохранённого path до запуска и при восстановлении.
Он не очищает base workspace, globals, функции или пользовательские фигуры.
Unit-окна временно скрыты; исполнитель закрывает только созданные тестом
фигуры и возвращает DefaultFigureVisible. Ошибка одного теста записывается
и не прерывает остальные. Видимые окна открывают только явно выбранные
интеграции через run_tests('integration') либо run_tests('all').

@CRITERION MATLAB-CONTEXT-001: только выделенный TCP-сервер перед заданием
вызывает service_pipeline_reset: очищает base workspace, globals,
незаблокированные функции/persistent и фигуры; восстанавливает стандартный
путь, проектные пути и seed 1729, обновляет кэш путей. TCP/timer и очередь живут
в функциональном контексте сервера. Между unit-тестами используется общий
безопасный исполнитель, без повторного сброса всей сессии.

@CRITERION MATLAB-CONTEXT-002: изменение теста и его зависимости между двумя
TCP-заданиями исполняется без смены PID сервера. Загрязнение base/global/persistent
из первого задания не доступно второму.

Сервер выделенный: пользовательские переменные и фигуры в нём не сохраняются.
Для работы в своей сессии используйте run_tests, без запуска TCP-сервера.
Не применять clear classes/delete(timerfindall): они затрагивают транспорт.
Активные и mlock-функции, классы с живыми экземплярами не гарантируются сбросом.
Изменение активного host/server требует отдельного перезапуска.
service_pipeline_host не имеет таймаута 1800 секунд. Штатная остановка:
создать runtime/pipeline/stop-server, когда нет активных заданий.

@CRITERION CONTEXT-VERSION-001: запрос test_sha256 проверяется до постановки
и после очистки; другой хеш для того же ID отклоняется. Отчёт содержит
test_sha256, host_pid и context_protocol=2. Без поля прежний режим сохраняется.
Проверяется только выбранный тест, не замыкание зависимостей.
