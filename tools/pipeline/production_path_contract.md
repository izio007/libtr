# Строгий производственный путь после миграции

Основание: .clinerules, задача 4 need_work.md.
Производственный путь содержит только matlab/function/ и matlab/engine/.
Корень matlab/ с альтернативными представлениями паспортов не является каталогом ядер.

@CRITERION PATH-001: проверка охватывает все .m в обоих производственных каталогах;
каждая функция разрешается однозначно из своего файла.
@CRITERION PATH-002: зависимости внутри репозитория допустимы только в этих
двух каталогах; mock и setup_test_paths недоступны на чистом production path.
@CRITERION PATH-003: запрещённые побочные эффекты/динамический вызов диагностируются
существующим статическим фильтром; детерминированный тест движка продолжает проходить.

Статический анализ не доказывает отсутствие всех динамических зависимостей.
Проверка не заменяет адресные численные тесты и сравнение эталонных графиков.
