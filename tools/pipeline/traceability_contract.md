# Статический граф явных связей: первый исполняемый срез

Основание: VPrincipe.md, REQ-VDESIGN-001 и REQ-VDESIGN-013.
Это контракт инструмента, не замена принципов и не подтверждение полноты графа проекта.

Вход: явный JSON-манифест с полями schema_version=1, nodes и edges.
Узел: id, kind, path (относительный путь существующего файла).
Связь: source, target, relation. Направление: от зависимого к основанию.
Типы узлов: contract, requirement, implementation, check, result.
Отношения: derives, depends, implements, verifies, evidence.
Файл узла хешируется целиком; блочная адресация и парсинг документов — следующий срез.
Привязка к файлу не заменяет устойчивый ID положения.

- @CRITERION TRACE-001: дубликаты ID, неизвестные концы связей, недопустимые типы,
  отсутствующие файлы и выход пути за корень отклоняются без публикации графа.
- @CRITERION TRACE-002: перестановка входных записей не меняет байты графа;
  граф содержит SHA-256 файлов, но не присваивает PASS требованиям.
- @CRITERION TRACE-003: обход прежних и новых связей сохраняет последствия
  удалённого ребра; обход оснований и зависимых выполняется раздельно, с защитой от циклов.
- @CRITERION TRACE-004: артефакт публикуется атомарно только под runtime/;
  существующий файл не перезаписывается. Входной манифест хранится вне runtime/.
- @CRITERION TRACE-005: diff по устойчивым ID различает добавление, удаление,
  изменение содержимого/типа и перенос пути. Изменение отношения связи считается
  удалением прежней и добавлением новой. Оба конца изменённых связей включаются
  в исходные причины; последствия определяются по объединению старых и новых связей.
- @CRITERION TRACE-006: одинаковые графы дают пустой diff; перестановка записей
  не влияет на результат. Несовместимая версия, повтор ID и оборванные связи
  в прежнем графе отклоняются, а не дают пустой анализ.

Интерфейс: traceability_builder.py ROOT MANIFEST OUTPUT [--previous GRAPH].
Пути CLI разрешаются относительно текущего каталога; path узла — относительно ROOT.
Выход: schema_version, nodes, edges, coverage=explicit_only,
verification_status=NOT_RUN. Успешное построение не доказывает полноту зависимостей.
Функция affected(old, new, seeds) возвращает отдельные множества ancestors
и dependents. compare(old, new) автоматически определяет исходные причины.
При --previous выход содержит поле impact. Перенос пути консервативно требует
проверки зависимостей, даже если хеш совпал. Полнота графа не предполагается;
актуальность свидетельств и математические исходы не присваиваются.

Проверка: python -m unittest discover -s tools/pipeline -p test_traceability_builder.py.
Графики ТИС этим инструментом не рассчитываются и не изменяются.
