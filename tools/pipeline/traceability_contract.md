# Необязательный инструмент явных связей

traceability_builder.py строит статический граф, если конкретной задаче
нужен такой анализ. Он не входит в обычный запуск тестов, не является
условием правки кода или правил и не требует сопровождать граф для каждой задачи.
Ниже описан существующий интерфейс, без плана расширения и регламента приёмки.

Вход — явный JSON с schema_version=1, nodes и edges.
Узел содержит id, kind, path относительно корня проекта. Связь содержит
source, target, relation; направление — от зависимого к основанию.
Типы узлов: contract, requirement, implementation, check, result.
Отношения: derives, depends, implements, verifies, evidence.
Хешируется весь файл. Блочного анализа математических документов здесь нет.

## Поведение существующего инструмента

- @CRITERION TRACE-001: дубликаты ID, неизвестные концы связей, недопустимые типы,
  отсутствующие файлы и выход пути за корень отклоняются без публикации графа.
- @CRITERION TRACE-002: перестановка записей не меняет байты графа;
  SHA-256 файлов не означает успешной проверки математических требований.
- @CRITERION TRACE-003: старые и новые связи учитываются при удалении ребра;
  обход оснований и зависимых выполняется раздельно, с защитой от циклов.
- @CRITERION TRACE-004: результат публикуется атомарно под runtime/;
  существующий файл не перезаписывается, входной манифест хранится вне runtime/.
- @CRITERION TRACE-005: сравнение по ID различает добавление, удаление,
  изменение содержимого/типа и перенос пути. Изменение отношения — удаление
  прежней и добавление новой связи; последствия учитывают оба графа.
- @CRITERION TRACE-006: одинаковые графы дают пустой diff; неверная версия,
  повтор ID и оборванные связи в прежнем графе приводят к ошибке.

## Вызов по необходимости

```sh
python tools/pipeline/traceability_builder.py ROOT MANIFEST OUTPUT --previous GRAPH
```

Параметр --previous необязателен. Пути CLI отсчитываются от текущего каталога,
path узла — от ROOT. Выход содержит schema_version, nodes, edges,
coverage=explicit_only и verification_status=NOT_RUN; при --previous также impact.
Функции affected(old, new, seeds) и compare(old, new) предоставляют анализ связей.
Перенос пути инструмент консервативно показывает как возможное влияние.
Полнота зависимостей и правильность численных результатов этим не доказываются.
