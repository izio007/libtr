# Перенос tis_cov2std без изменения математики

Основание: .clinerules, need_work.md задача 4.
Источник matlab/tis_cov2std.m, цель matlab/function/tis_cov2std.m.

@CRITERION MOVE-COV2STD-001: сохранить байты и SHA-256
5f1cbda0a9657b98a3f84a40f4e3d726eda68fc260f5a6e95d1a9ef2764130cd;
отсутствие старого файла, единственная функция на чистом production path.
@CRITERION MOVE-COV2STD-002: существующие 2D/3D проверки проходят до/после;
независимый диагональный пример даёт радиусы 2,3,4 вдоль осей при K=diag(4,9,16).

Перенос не закрывает замечания docs/guides/PASSPORT_CORRECTION_REVIEW.md:
радиусы сечений не тождественны проекционным СКО; пороги и валидация требуют
отдельной работы. Существующие тесты проверяют допуск, а не побитовое доказательство.
Код ядра, критерии существующих тестов и эталоны не меняются.
Полный графический контроль комплекса остаётся отдельным открытым пунктом.
Исторические результаты относятся к прежним байтам контрактов; изменение целевого пути не переаттестовывает их. Текущая архитектура — .clinerules.
