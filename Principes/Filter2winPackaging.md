# Архив filter2win

Из корня репозитория создайте архив с новым номером версии:

```sh
python tools/package_filter2win.py --version VERSION --output Release
```

Для включения HTML, рисунков и локального отображения формул добавьте
`--include-html`. Архив распаковывается целиком; HTML находится в
`docs/html/filter2win.html`.

Состав задан в одном списке упаковщика: исходники, проверки поведения,
данные и теория. Отсутствующий исходник или существующий архив дают ошибку.
Упаковка не запускает MATLAB, сервер или отдельную процедуру приёмки.
Проверки вычислений запускаются по [общей методике](testing_methodology.md).
