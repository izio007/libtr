# ZIP исходников filter2win

Из корня проекта:

```sh
python3 tools/package_filter2win.py --version 0.3.1 --output Release
```

На Windows можно использовать python. Результат — Release/filter2win-0.3.1.zip.
Явный список FILES в скрипте задаёт MATLAB-функции, обычные тесты, настройки
и Markdown; скрипт добавляет VERSION и README с примерами запуска.
Отсутствующий исходник или уже существующий архив дают понятную ошибку.

Упаковка не запускает MATLAB, сервер, экспорт или особую приёмку. Если нужно
проверить вычисления, вызови нужные обычные тесты отдельно, в том числе
непосредственно из MATLAB Desktop. Другой формат документа создаётся
отдельным скриптом по задаче пользователя и не является условием ZIP.
