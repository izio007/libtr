# LIBTR: достаточная проверка изменений

Проверка отвечает на конкретный вопрос о коде или численном результате.
Она не создаёт самостоятельный процесс согласования. Общий порядок:
задача → минимальная правка → необходимая проверка → результат → стоп.

## Что проверять

- Для вычислительного метода — независимые аналитические случаи, инварианты,
  численные допуски и существенные границы его области применения.
- Для состояния — последовательность переходов и сохранение данных при отказе.
- Для взаимодействия — только затронутые входы, выходы и порядок вызовов.
- Для исправленного дефекта — случай, который воспроизводит этот дефект.

Существующие математические тесты сохраняются. Новая проверка нужна, если
она ловит существенную ошибку, а не повторяет реализацию другими словами.
Для небольшого изменения достаточно относящихся к нему проверок. Полный
прогон не является обязательным сопровождением любой правки.

Ожидания должны иметь независимое основание. При отказе выясни, неверны ли
входы, тест, реализация или модель. Не расширяй допуск, чтобы скрыть ошибку.
Предусмотренный отказ проверяется по ожидаемому статусу и состоянию;
отсутствие исключения само по себе не доказывает правильность вычисления.

## Когда остановиться

После исправления и нужной проверки сообщи результат и завершай задачу.
Новый запуск обоснован реальным изменением, обнаруженным дефектом или запросом
пользователя. Отсутствующая карточка, новый отчёт или смена оформления не
являются основанием повторять расчёт. Старые результаты остаются историей;
не выдавай их за выполненный запуск изменённого кода.

## Что сюда не входит

Для правил проекта не нужны тесты, графы требований, взаимные согласования
или проверка соблюдения этой методики. Связь теста с назначением кода должна
быть понятна из кода и краткого пояснения, без обязательного манифеста.
Перевод Markdown в HTML, PDF и Live Editor решается отдельным скриптом
под нужный результат. Тесты переводчика, паспорта форматов и приёмочные
ворота не создаются. При конкретной ошибке оформления исправь её и получи
нужный файл; математические расчёты ради этого не повторяются.
