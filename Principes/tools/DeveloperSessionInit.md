# Начало работы в libtr

1. Прочитай задачу пользователя и .clinerules в текущем репозитории.
2. Посмотри состояние Git и только относящиеся к задаче исходники.
   need_work.md и историю открывай, если они нужны для продолжения этой темы.
3. Выполни минимальную правку или подготовь один скрипт под задачу.
4. Проверь изменённый код в необходимом объёме, сообщи результат и остановись.

Уже разрешённая работа не требует отдельной команды после инициализации.
Не создавай обязательную карточку, паспорт, граф связей или очередь согласований.
Не читай весь архив и не запускай всё заново только из-за нового сеанса.

Разрешены MATLAB Desktop и непосредственный вызов функций. Для обычного
запуска из корня проекта: addpath('matlab'); status = run_tests;
Для поиска конкретной ошибки можно вызвать соответствующий тест отдельно.
Не очищай рабочее пространство пользователя и не останавливай его процессы.

Сохраняй математические тесты, независимые эталоны и чужие изменения.
Преобразование представлений решай скриптом без дополнительных тестов
и приёмочных процедур. Не называй невыполненный запуск успешным.
Повторяй работу только при конкретном изменении, дефекте или новой команде.
