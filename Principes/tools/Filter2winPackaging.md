# Упаковка исходников filter2win

Единственный сборщик исходного ZIP — `tools/package_filter2win.py`.
Из корня репозитория:

```sh
python3 tools/package_filter2win.py --version 0.3.1 --output Release
```

На Windows допустима команда `python` вместо `python3`.
Результат: `Release/filter2win-0.3.1.zip`, с корневым каталогом
`filter2win-0.3.1` внутри архива. Выходной каталог создаётся при необходимости.

Состав исходников задан одним явным списком `FILES` в сборщике: MATLAB-функции,
конфигурации, обычные тесты и их вспомогательные функции, Markdown-паспорта.
Сборщик копирует их байты без изменения и добавляет `VERSION` и `README.md`
с примером использования и командами ручного запуска включённых тестов.

Параметр `--version` обязателен; допустимы буквы, цифры, точки, дефисы и
подчёркивания. `--output` указывает каталог ZIP. Существующий архив не
перезаписывается: для нового результата выбирается другая версия или каталог.
Отсутствующий исходный файл останавливает создание архива.

Команда только упаковывает файлы. MATLAB, тесты, серверы и экспорт документов
она не запускает; состояние рабочего host не меняется. Проверки исходного
репозитория выполняются отдельно через `tools/runner.sh <config.json>`.
При необходимости дополнительные форматы документации создаются отдельной
явной командой и не являются условием создания ZIP.

Созданный архив не получает автоматически статус проверенной математики.
Сведения о выполненных проверках относятся к конкретному прогону и его версии.
