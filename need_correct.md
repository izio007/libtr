# Предложения по исправлению утверждённых регламентов

Только открытые предложения в формате «Было → Стало».
Отклонённые, эквивалентные и выполненные правки удаляются.

## 2. Размещение выпускных представлений

Файл: .clinerules, положение об autogen/. Основание: удаление Шефом
производных .m/.pdf и указание генерировать их при Release в выходные архивы.

**Было:** autogen/ — производные HTML/Live Editor представления математики,
HTML требований и методик испытаний.

**Стало:** Представления Markdown генерируются только по прямой команде
при выпуске версии в каталог выходных архивов Release. В matlab/ производные
паспорта не хранятся и для расчётных тестов не требуются. Состав форматов
и путь выпускного каталога фиксируются в контракте выпуска; ручная
содержательная правка производных запрещена.
