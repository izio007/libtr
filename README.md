# libtr

MATLAB-библиотека триангуляции, оценки координат и обработки наблюдений. Исходники включают LLS, WLLS, GN/GNP, информационные реперы, filter2win и тракт ВОИ/ОИНО для неподвижной цели с движущимся наблюдателем.

## Запуск в MATLAB

Из корня репозитория:

```matlab
addpath('matlab');
status = run_tests;
```

Это запуск unit-тестов. Фактический результат, журнал и каталог вывода возвращаются в `status`; наличие команды в документации не означает, что проверки уже выполнены в вашей среде.

Для выбранной интеграции с графиками:

```matlab
status = run_tests('integration', {'filter2win'});
```

Доступные интеграции: `filter2win`, `context30`, `context450`, `tis`. Поддерживаемые режимы описаны непосредственно в [run_tests.m](matlab/run_tests.m). Правка документации сама по себе не требует повторного расчёта испытаний.

## Проектирование и состояние реализации

Изменение начинается с требуемого результата, условий применения и границ ответственности. Затем определяются сценарии и обмен, поведение и владельцы состояния, вычисления, публикация результата и наблюдаемые проверки. Материалы 1–8 можно вести разделами одного предметного документа; используются применимые части.

Для ВОИ уже существуют вычислительные функции, описание синхронного тракта, ОИНО и коррекции. В конкретном изделии отдельно задаются внешние участники, транспорт, требования к точности и задержке, аппаратная платформа и применимый интерфейс оператора. Их выбор фиксируется по исходным требованиям. Статус реализации и результаты испытаний берутся из действующих исходников и фактических запусков.
