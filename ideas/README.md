# Архитектурные описания libtr

Здесь хранятся долговременные архитектурные решения и регламенты проектирования
инструментов. Это не математические паспорта методов и не отчеты запусков.
У каждого документа явно указаны статус решения и состояние реализации.
Согласованный проектный контракт не означает, что соответствующий инструмент
уже реализован и проверен.

Файлы нумеруются последовательно: 01_, 02_, …, 99_. Номера не переиспользуются.
История изменений хранится в Git; временные материалы — в runtime/.
Запросы и результаты отдельных коммитов остаются в proposals/, без копирования
туда полного текста архитектурного регламента.

| Документ | Назначение | Состояние |
|---|---|---|
| [01_provenance_impact_analysis.md](01_provenance_impact_analysis.md) | Происхождение результатов и адресная инвалидация | Проектный контракт зафиксирован; реализация не подтверждена |
| [02_v_design_3r.md](02_v_design_3r.md) | V-проектирование, три представления и соответствующие уровни проверки | Регламент зафиксирован; миграция и внедрение не подтверждены |

Документы этого каталога не отменяют корневые регламенты. Противоречия с ними
выносятся на согласование. Миграция структуры 3R оформляется отдельно.
