# Произведение трёх матриц

## Назначение и исходные данные

Операция последовательно применяет три линейных преобразования. На входе —
вещественные матрицы согласованных размеров; на выходе — их произведение
с фиксированным порядком скобок:

```math
A\in\mathbb R^{m\times n},\quad B\in\mathbb R^{n\times p},\quad
C\in\mathbb R^{p\times q},\qquad D=(AB)C\in\mathbb R^{m\times q}.
```

Например, преобразование ковариации часто имеет такой вид. Единицы результата
определяются единицами множителей. Обратимость матриц не требуется.

## Как получается результат

Сначала образуется промежуточная матрица, затем итоговая:

```math
T_{il}=\sum_{k=1}^{n}A_{ik}B_{kl},\qquad
D_{ij}=\sum_{l=1}^{p}T_{il}C_{lj}.
```

Таким образом, каждая величина результата равна двойной сумме:

```math
D_{ij}=\sum_{l=1}^{p}\sum_{k=1}^{n}A_{ik}B_{kl}C_{lj}.
```

Небольшой пример можно проверить вручную:

```math
A=\begin{bmatrix}1&2\\3&4\end{bmatrix},\quad
B=\begin{bmatrix}5&6\\7&8\end{bmatrix},\quad
C=\begin{bmatrix}1\\2\end{bmatrix},\qquad
AB=\begin{bmatrix}19&22\\43&50\end{bmatrix},\quad
D=\begin{bmatrix}63\\143\end{bmatrix}.
```

## Границы и точность

Несогласованные размеры или нечисловые бесконечные значения не дают допустимого
результата. Если промежуточное произведение переполняется, вычисление также
непригодно, даже если иной порядок скобок мог бы дать конечный ответ.

В точной арифметике умножение ассоциативно. В вычислительной арифметике иной
порядок суммирования может изменить округление. Поэтому порядок скобок входит
в определение операции; побитовое совпадение разных вычислителей не обещается.

При нулевом числе слагаемых сумма равна нулю. Если число строк или столбцов
выхода равно нулю, результат пуст и сохраняет требуемые размеры. Проверка
конечности входов предшествует этим правилам.

## Независимая проверка

@CRITERION MATMUL3-VERIFY-001: Проверяются ручные примеры, прямоугольные и нулевые размеры,
вырожденные матрицы, переполнение каждого этапа и неизменность входов при отказе.
Для дробных данных независимый расчёт использует двойную сумму. В существующих
небольших контрольных примерах сравнение задаётся так:

```math
S_{ij}=\sum_{k=1}^{n}\sum_{l=1}^{p}|A_{ik}B_{kl}C_{lj}|,\qquad
\tau_{ij}=32\epsilon(n+p+1)\max(1,S_{ij}),\qquad
|D_{ij}-D^{\rm ref}_{ij}|\le\tau_{ij}.
```

Здесь $`\epsilon`$ — расстояние от единицы до следующего представимого числа
двойной точности. Этот допуск относится к выбранным испытаниям, а не является
универсальной оценкой ошибки для любых матриц.

Поддерживаемые типы и способы сообщения об отказе указаны в
[исходнике](../matlab/function/matmul3.m), контрольные примеры —
в [испытании](../matlab/tests/unit_test_matmul3.m).
