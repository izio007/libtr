# Линейная оценка координат по направлениям — LLS

## Для чего нужен метод

Несколько постов видят одну цель под разными углами. Метод находит одну точку,
которая лучше всего согласуется с полученными направлениями в линейной
постановке. Начальное приближение не требуется.

На входе — координаты постов и измеренные азимуты и углы места.
На выходе — оценка трёх координат цели. Координаты задаются в метрах,
углы — в радианах. Оси направлены на восток, север и вверх; азимут
отсчитывается от положительной оси востока к северу.

## От направления к двум уравнениям

Пусть $`\mathbf X`$ — искомая точка, $`\mathbf s_i`$ — положение поста,
$`\alpha_i,\beta_i`$ — его углы. Направление на цель:

```math
\mathbf u_i=
\begin{bmatrix}
\cos\alpha_i\cos\beta_i\\
\sin\alpha_i\cos\beta_i\\
\sin\beta_i
\end{bmatrix}.
```

Два перпендикулярных этому направлению вектора задают плоскости, пересечение
которых содержит прямую наблюдения:

```math
\mathbf h_{a,i}=
\begin{bmatrix}\sin\alpha_i\\-\cos\alpha_i\\0\end{bmatrix},\qquad
\mathbf h_{b,i}=
\begin{bmatrix}-\cos\alpha_i\sin\beta_i\\-\sin\alpha_i\sin\beta_i\\\cos\beta_i\end{bmatrix}.
```

Для точного наблюдения обе поперечные составляющие расстояния до прямой равны нулю:

```math
\mathbf h_{a,i}^{T}(\mathbf X-\mathbf s_i)=0,\qquad
\mathbf h_{b,i}^{T}(\mathbf X-\mathbf s_i)=0.
```

Собрав эти строки по всем $`M`$ постам, получаем $`H\mathbf X=\mathbf b`$.
Матрица $`H`$ имеет $`2M`$ строк и три столбца, а соответствующие элементы
$`\mathbf b`$ равны $`\mathbf h_{a,i}^{T}\mathbf s_i`$ и
$`\mathbf h_{b,i}^{T}\mathbf s_i`$. Остатки имеют размерность метра.

## Что минимизируется

При ошибках измерения все плоскости обычно не проходят через одну точку.
Выбирается минимум суммы квадратов их остатков:

```math
\widehat{\mathbf X}=\mathop{\mathrm{arg\,min}}\limits_{\mathbf X}
\|H\mathbf X-\mathbf b\|^2,\qquad
H^TH\widehat{\mathbf X}=H^T\mathbf b.
```

Если ранг $`H`$ равен трём, решение единственно:

```math
\widehat{\mathbf X}=(H^TH)^{-1}H^T\mathbf b.
```

Запись через обратную матрицу выражает решение; выбор численного способа
его вычисления относится к реализации.

## Когда результату нельзя доверять

Для восстановления трёх координат нужен полный ранг. Одного числа постов
недостаточно: почти параллельные направления плохо определяют дальность.
Конечная оценка при такой геометрии может иметь большую ошибку.

Критерий использует расстояния до прямых, а не непосредственно угловые ошибки.
Он также сам по себе не запрещает точку позади поста. При шуме коэффициенты
$`H`$ и $`\mathbf b`$ случайны и связаны между собой. Поэтому несмещённость и
оптимальность обычной линейной задачи с точно известной матрицей нельзя
автоматически переносить на эту засечку. Направление и величина смещения
зависят от геометрии и распределения ошибок.

## Что проверять

При точных углах и полном ранге должна восстанавливаться заданная точка
с учётом численного допуска. Перенос начала координат должен переносить
результат на ту же величину. Отдельно проверяются недостаточная геометрия,
почти параллельные направления и переход азимута через границу периода.
На шумовых данных сравнивают смещение, разброс и долю отказов, а не только
несколько удачных оценок.
