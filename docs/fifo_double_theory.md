# Хранение последних наблюдений: FIFO

## Зачем нужна очередь

Фильтру нужна ограниченная история реальных наблюдений. Очередь хранит пары
«время — значение» в порядке поступления. Когда места больше нет, новое
наблюдение вытесняет самое старое. Обозначение FIFO означает именно этот порядок.

**F2W-S2-03.** Вместимость задаётся положительным целым числом. Время нового
наблюдения должно быть строго больше времени последнего принятого наблюдения.
Время и значение конечны. Единицы значения выбирает задача; очередь их не меняет.

## Что происходит с историей

| Действие | Результат |
|---|---|
| Добавление при свободном месте | Новая пара появляется в конце истории |
| Добавление в полную очередь | Удаляется одна самая старая пара |
| Чтение | Возвращаются сохранённые пары от старой к новой, история не меняется |
| Извлечение старой пары | Удаляется только первая пара |
| Удаление по времени | Удаляются пары строго раньше заданной границы; равенство сохраняется |
| Полная очистка | Удаляется вся история и начинается новая последовательность времени |
| Ошибочное действие | История остаётся прежней |

Например, при вместимости три пары последовательность времён 1, 4, 9 после
приёма времени 12 становится 4, 9, 12. Неравные интервалы допустимы.
Прогноз фильтра не является новым наблюдением и не должен попадать в очередь.

Обычное удаление не снимает требование возрастающего времени: даже если очередь
опустела, ранее принятая временная граница сохраняется. Только полная очистка
начинает новую последовательность. Чтение пустой очереди возвращает пустую историю.

## Исключение выявленных выбросов

**F2W-S3-01.** Можно явно выбрать сохраняемые пары. Остальные удаляются физически;
порядок оставшихся, вместимость и временная граница сохраняются. Выбор всех пар
ничего не меняет, выбор ни одной оставляет пустую историю.

В [двухоконном фильтре](filter2win_theory.md) такое удаление составляет единое
действие с пробным добавлением. Если новая точка отвергнута, отменяются и её
добавление, и пробное вытеснение, и удаление старых выбросов. Сама очередь
не определяет, является ли точка выбросом.

## Что проверять

Независимые примеры должны подтверждать порядок, сохранение дробных значений,
вытеснение при заполнении, включённую временную границу, выборочное удаление
и неизменность истории при отказе. Очередь обслуживает обе схемы фильтра;
различаются правила её использования.

Программный интерфейс описан в [исходнике](../matlab/function/fifo_double.m),
проверки — в [испытании очереди](../matlab/tests/unit_test_fifo_double.m).
Наличие этих файлов не является свидетельством нового успешного запуска.
