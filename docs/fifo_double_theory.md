# FIFO пар double для filter2win

## Контракт F2W-FIFO-001
`[status,state,value,time] = fifo_double(action,state,value,time)`.
Чистое ядро хранит пары конечных вещественных скаляров double без приведения
к int32. Время имеет единицы секунд; FIFO не навязывает монотонность,
её проверяет потребитель. Действия задаются символьной строкой.

- `init`: value — целая положительная ёмкость; создаются два массива этой
  длины, count=0, head=1. Предыдущее состояние не используется.
- `push`: записать пару в хвост, при заполнении вытеснить старейшую пару.
- `get`: value — индекс 1..count в хронологическом порядке; вернуть пару
  без изменения состояния. Чтение пустого окна — отказ.
- `clear`: сбросить count и head без очистки или изменения размеров массивов.
  Старое содержимое за пределами логического окна недоступно через get.

status=0 — успех; status=1 — неверное действие, вход или структура состояния,
состояние не меняется. При отказе выходные value/time не являются данными.
При init/clear они NaN. Нулевая ёмкость запрещена. Проверяются типы/размеры
буферов, границы целых count/head. Содержимое состояния, созданного ядром,
нельзя редактировать вручную; полная проверка повреждения всех ячеек не заявлена.

## Память F2W-FIFO-002
Выделение массивов выполняется в init до тактов; push/get/clear не меняют их
размеры и не сдвигают элементы. head указывает старейший элемент; индекс
логического элемента j равен mod(head+j-2,capacity)+1.
Это инвариант структуры, не доказательство отсутствия внутренних выделений
MATLAB (в том числе copy-on-write). Строгий Zero-Allocation требует отдельного
измерения на целевой среде; до него статус NOT_RUN.
Существующие int32 fifo_* не изменяются и имеют самостоятельный контракт.

## Проверки и связи
Реализация: matlab/function/fifo_double.m; потребитель: matlab/function/filter2win.m.
Проверка: matlab/tests/unit_test_fifo_double.m; данные:
matlab/tests/configs/fifo_double_cases.json (не конфигурация запуска раннера).
F2W-FIFO-CHK-001: независимые ожидаемые пары после переполнения и оборота,
дробные числа, размер буферов, очистка, ёмкость 1, неверный индекс/count/размер
и нулевая ёмкость; отказ не меняет состояние. Исполнение NOT_RUN до регистрации
адресного suite в штатном раннере. Регрессионная проверка потребителя —
matlab/tests/unit_test_filter2win.m и unit_test_filter2win_relocation.m.
