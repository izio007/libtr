# Уточнение направления и дальности — GNP

Метод решает ту же угловую задачу, что [Гаусс — Ньютон](gn_theory.md), но
уточняет азимут, угол места и дальность относительно центра постов.
Такое представление удобно, когда продольная и поперечная ошибки существенно
различаются. Смена координат не добавляет информации и не гарантирует устранения
смещения.

На входе нужны положения постов, углы и начальное приближение.
На выходе — координаты цели в метрах. Углы внутри метода выражаются в радианах.


## 1. Координаты относительно центра постов
Пассивная измерительная сеть ТИС состоит из M наземных постов с известными декартовыми координатами в локальной прямоугольной системе ENU (East-North-Up):

```math
\mathbf{X}_{si} = [x_{si}, y_{si}, z_{si}]^T, \quad i = 1, \dots, M
```

В качестве опорной точки выбирается геометрический центр тяжести куста постов:

```math
\displaystyle \mathbf{X}_0 = [x_0, y_0, z_0]^T = \frac{1}{M}\sum_{i=1}^{M}\mathbf{X}_{si}
```

Вектор нелинейного состояния объекта Y параметризуется тремя сферическими координатами относительно полюса X_0 в абсолютных единицах СИ (метры, радианы):

```math
\mathbf{Y} = [\alpha_0, \beta_0, R_0]^T
```

Аналитический переход от текущего полярного вектора состояния Y к абсолютным декартовым координатам объекта на земле X = [x, y, z]^T (в метрах) является точным и непрерывным:

```math
\mathbf{X}(\mathbf{Y}) = \begin{bmatrix} x(\mathbf{Y}) \\ y(\mathbf{Y}) \\ z(\mathbf{Y}) \end{bmatrix} = \begin{bmatrix} x_0 + R_0 \cos\beta_0 \cos\alpha_0 \\ y_0 + R_0 \cos\beta_0 \sin\alpha_0 \\ z_0 + R_0 \sin\beta_0 \end{bmatrix}
```

## 2. Чувствительность углов к параметрам цели
Производные получаются по правилу дифференцирования сложной функции: производная углов по декартовым координатам умножается на производную координат по полярным параметрам.

## Производные по первому столбцу Якобиана (по азимуту $`\alpha_0`$):

```math
J_{\text{GNP}}(2i-1, 1) = \frac{\partial \alpha_i}{\partial \alpha_0} = \frac{R_0 \cos\beta_0 \cdot (\Delta x_i \cos\alpha_0 + \Delta y_i \sin\alpha_0)}{r_{h,i}^2}
```

```math
J_{\text{GNP}}(2i, 1) = \frac{\partial \beta_i}{\partial \alpha_0} = \frac{R_0 \Delta z_i \cos\beta_0 \cdot (\Delta x_i \sin\alpha_0 - \Delta y_i \cos\alpha_0)}{r_i^2 \cdot r_{h,i}}
```

## Производные по второму столбцу Якобиана (по углу места $`\beta_0`$):

```math
J_{\text{GNP}}(2i-1, 2) = \frac{\partial \alpha_i}{\partial \beta_0} = \frac{R_0 \sin\beta_0 \cdot (\Delta y_i \cos\alpha_0 - \Delta x_i \sin\alpha_0)}{r_{h,i}^2}
```

```math
J_{\text{GNP}}(2i, 2) = \frac{\partial \beta_i}{\partial \beta_0} = \frac{R_0 \cdot \left[ r_{h,i}^2 \cos\beta_0 + \Delta z_i \sin\beta_0 (\Delta x_i \cos\alpha_0 + \Delta y_i \sin\alpha_0) \right]}{r_i^2 \cdot r_{h,i}}
```

## Производные по третьему столбцу Якобиана (по линейной дальности в метрах R_0):

```math
J_{\text{GNP}}(2i-1, 3) = \frac{\partial \alpha_i}{\partial R_0} = \frac{\cos\beta_0 \cdot (\Delta x_i \sin\alpha_0 - \Delta y_i \cos\alpha_0)}{r_{h,i}^2}
```

```math
J_{\text{GNP}}(2i, 3) = \frac{\partial \beta_i}{\partial R_0} = \frac{r_{h,i}^2 \sin\beta_0 - \Delta z_i \cos\beta_0 (\Delta x_i \cos\alpha_0 + \Delta y_i \sin\alpha_0)}{r_i^2 \cdot r_{h,i}}
```

Где пространственные приращения определяются относительно i-го поста ТИС:

```math
\Delta x_i = x - x_{si}, \quad \Delta y_i = y - y_{si}, \quad \Delta z_i = z - z_{si}
```

```math
r_{h,i} = \sqrt{\Delta x_i^2 + \Delta y_i^2}, \quad r_i = \sqrt{r_{h,i}^2 + \Delta z_i^2}
```

## 3. Шаг уточнения и остановка
На каждом k-м шаге МНК Гаусса-Ньютона расчет приращения ведется без весовых матриц Гаусса-Маркова (равноточные измерения):

```math
(J_{\text{GNP}}^T \cdot J_{\text{GNP}}) \cdot \Delta \mathbf{Y} = J_{\text{GNP}}^T \cdot \mathbf{residual}
```

После вычисления поправки обновляются параметры:
1. Принудительная тригонометрическая редукция фазы азимута на границе $`\pm\pi`$:

```math
\alpha_0^{(k+1)} = \text{atan2}\left(\sin(\alpha_0^{(k)} + \Delta \alpha_0), \ \cos(\alpha_0^{(k)} + \Delta \alpha_0)\right)
```

2. Обновление угла места и дальности в метрах:

```math
\beta_0^{(k+1)} = \beta_0^{(k)} + \Delta \beta_0
```

```math
\mathbf{R}_0^{(k+1)} = R_0^{(k)} + \Delta R_0
```

### Остановка
Итерации прекращаются, когда предсказанное изменение всех углов меньше заданного допуска в радианах:

```math
\max \left\vert{} J_{\text{GNP}} \cdot \Delta \mathbf{Y} \right\vert{} < \epsilon_{\text{angle}}
```

## 4. Пересчёт матрицы разброса
При единичной ковариации углового шума линейное приближение полярной ковариации имеет вид:

```math
K_{\text{polar}} = \left( J_{\text{GNP}}^T \cdot J_{\text{GNP}} \right)^{-1}
```

### Разделение масштаба дальности
Для явного выделения масштаба дальности угловые столбцы матрицы перехода делятся на дальность. Получается следующая матрица:

```math
\bar{J}_{\text{polar}\rightarrow\text{cart}} = \begin{bmatrix} -\cos\beta_0 \sin\alpha_0 & -\sin\beta_0 \cos\alpha_0 & \cos\beta_0 \cos\alpha_0 \\ \cos\beta_0 \cos\alpha_0 & -\sin\beta_0 \sin\alpha_0 & \cos\beta_0 \sin\alpha_0 \\ 0 & \cos\beta_0 & \sin\beta_0 \end{bmatrix}
```

Соответственно, перед разворотом полярная ковариационная матрица нормируется симметричным преобразованием с диагональной матрицей M_norm = diag(R_0, R_0, 1):

```math
K_{\text{polar\_norm}} = M_{\text{norm}} \cdot K_{\text{polar}} \cdot M_{\text{norm}}
```

Финальный декартов тензор ошибок рассеяния целей K_cart в квадратных метрах локальной системы координат формируется как единый, матричное преобразование:

```math
K_{\text{cart}} = \bar{J}_{\text{polar}\rightarrow\text{cart}} \cdot K_{\text{polar\_norm}} \cdot \bar{J}_{\text{polar}\rightarrow\text{cart}}^T
```

Недостаточный ранг или непригодная обусловленность не позволяют получить достоверную поправку и матрицу разброса.


## 5. Область применимости и проверка

При нулевой дальности или полярном направлении параметризация вырождается.
Малый расчётный шаг не доказывает достижения глобального минимума.
Допуск остановки задаётся до опыта; он не является допустимой ошибкой координаты.

Нормированный пересчёт ковариации алгебраически эквивалентен обычному переходу
по производным. Он не даёт универсальной гарантии сохранения точности.
Для реальных дисперсий углов требуется согласовать модель шума и матрицу
разброса; единичный шум в записанной формуле — явное ограничение.

Проверяются обратный переход к координатам, производные, периодичность азимута,
особые направления, одинаковая геометрия в разных параметризациях и зависимость
от начала итераций. Эмпирическая ошибка сравнивается с расчётным разбросом
отдельно от проверки правильности преобразований.
