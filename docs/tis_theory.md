# Триангуляция: от направлений к координатам и оценке точности

## Общая идея

Один пост определяет направление на цель, но не её дальность. Несколько
пространственно разнесённых направлений позволяют оценить общую точку.
Из-за ошибок углов лучи обычно не пересекаются точно; метод выбирает точку
по заранее определённому критерию согласия с наблюдениями.

На входе — положения постов, углы и, для статистической оценки точности,
модель ошибок измерения. На выходе — координаты и характеристика их
неопределённости. Истинная координата используется только в контрольном опыте.

Координаты задаются в метрах, углы — в радианах, время — в секундах.
Локальные оси направлены на восток, север и вверх. Для неподвижной цели
можно объединять наблюдения разных моментов, сохраняя положение и ориентацию
наблюдателя на момент каждого измерения.

## Геометрия направления

Пусть $`\mathbf X`$ — цель, $`\mathbf s_i`$ — пост. Обозначим
$`\Delta\mathbf X_i=\mathbf X-\mathbf s_i`$,
$`r_{h,i}=\sqrt{\Delta x_i^2+\Delta y_i^2}`$,
$`\rho_i=\|\Delta\mathbf X_i\|`$.

```math
\alpha_i=\mathrm{atan2}(\Delta y_i,\Delta x_i),\qquad
\beta_i=\mathrm{atan2}(\Delta z_i,r_{h,i}),\qquad
\mathbf u_i=
\begin{bmatrix}\cos\alpha_i\cos\beta_i\\
\sin\alpha_i\cos\beta_i\\\sin\beta_i\end{bmatrix}.
```

Азимут отсчитывается от востока к северу, угол места — от горизонтальной
плоскости вверх. Вектор $`\mathbf u_i`$ единичный, а точное наблюдение задаёт луч

```math
\mathbf X=\mathbf s_i+\rho_i\mathbf u_i,\qquad \rho_i>0.
```

Исключить неизвестную дальность можно векторным произведением:

```math
[\mathbf u_i]_\times(\mathbf X-\mathbf s_i)=0,\qquad
[\mathbf u]_\times=
\begin{bmatrix}0&-u_z&u_y\\u_z&0&-u_x\\-u_y&u_x&0\end{bmatrix}.
```

Эти уравнения содержат два независимых ограничения. Их линейная форма
разобрана в [LLS](lls_theory.md). Исключение дальности даёт прямую;
принадлежность положительному лучу требует отдельного условия.

## Как различаются методы

| Метод | Что сравнивает | Особенность |
|---|---|---|
| [LLS](lls_theory.md) | Поперечные расстояния до прямых наблюдения | Линейная засечка без начальной точки |
| [WLLS](wlls_theory.md) | Взвешенные линейные остатки | Веса зависят от ошибок углов и предварительной дальности |
| [GN](gn_theory.md) | Углы измерения и углы предполагаемой точки | Последовательное уточнение координат |
| [GNP](gnp_theory.md) | Те же угловые остатки | Уточнение направления и дальности |

Ни один вариант не устраняет недостаток геометрической информации.
Почти параллельные направления особенно плохо определяют дальность.
Число постов само по себе не гарантирует единственности или точности.

Для углового критерия измерения объединены в $`\mathbf U`$, а расчётные
углы предполагаемой точки — в $`\Psi(\mathbf X)`$. При ковариации ошибок
$`\Sigma`$ взвешенный критерий имеет вид

```math
\Phi(\mathbf X)=(\mathbf U-\Psi(\mathbf X))^T
\Sigma^{-1}(\mathbf U-\Psi(\mathbf X)).
```

Азимутальные разности приводятся к основной ветви периода. Матрица $`\Sigma`$
диагональна только при некоррелированных ошибках. Линейный критерий расстояний
и угловой критерий различаются; их веса нельзя смешивать.

## Что означает расчётная точность

Матрица производных $`J`$ показывает чувствительность углов к координатам.
При гауссовских ошибках с постоянной заданной ковариацией информационная
матрица и её обратная имеют вид

```math
I_F=J^T\Sigma^{-1}J,\qquad K_F=I_F^{-1}.
```

При соответствующих условиях граница Крамера — Рао ограничивает снизу
ковариацию несмещённых оценок. Она не обещает достижимость для любого метода.
Для нелинейной оценки матрица, вычисленная в найденной точке, обычно служит
локальным приближением. Смещение, выбросы и ошибки навигации требуют
отдельного учёта.

Замена декартовых координат полярными не добавляет информации. Если
$`D=\partial\mathbf X/\partial\mathbf q`$ — матрица перехода производных, то

```math
J_q=JD,\qquad I_q=D^TI_FD,\qquad K_X\approx DK_qD^T.
```

Матрица $`D`$ в общем случае не ортогональна: её столбцы имеют разные масштабы.
При полярных особенностях переход может быть вырожден.

## Проекция, сечение и главные оси — разные характеристики

Пусть $`K`$ — положительно определённая ковариация в квадратных метрах,
а $`\mathbf e`$ — единичное направление.

| Величина | Формула | Смысл |
|---|---|---|
| СКО проекции | $`\sqrt{\mathbf e^TK\mathbf e}`$ | Разброс скалярной ошибки вдоль направления |
| Радиус сечения | $`1/\sqrt{\mathbf e^TK^{-1}\mathbf e}`$ | Расстояние от центра до единичного эллипсоида вдоль прямой |
| Главная полуось | $`\sqrt{\lambda_j(K)}`$ | Радиус вдоль собственного вектора |

Поворот $`R^TKR`$ корректен для ковариации в новом ортонормированном базисе.
Поворот $`R^TK^{-1}R`$ нужен для направленных сечений. Эти операции отвечают
на разные вопросы. Радиус сечения не следует подписывать как СКО проекции.

Для направления на цель и двух поперечных направлений можно построить базис

```math
\mathbf u_r=\frac{\mathbf X-\mathbf X_0}{\|\mathbf X-\mathbf X_0\|},\qquad
\mathbf u_1=\frac{[-u_{ry},u_{rx},0]^T}{\sqrt{u_{rx}^2+u_{ry}^2}},\qquad
\mathbf u_2=\mathbf u_r\times\mathbf u_1,\qquad R=[\mathbf u_r,\mathbf u_1,\mathbf u_2].
```

При вертикальном направлении формула для $`\mathbf u_1`$ не определена.
Это особенность выбранного базиса, а не доказательство невозможности цели
в этом направлении. Численные ограничения конкретного расчёта сохраняются
в исходнике; их физическое обоснование остаётся отдельным вопросом.

## Как проверять результат

Проверка начинается с точной геометрии и независимых производных.
Затем исследуются ошибки на повторных наблюдениях: смещение среднего,
разброс относительно среднего, среднеквадратическая ошибка относительно
истины и доля отказов. Если статистика считается только по успешным решениям,
это условие явно указывается.

[Информационный ориентир](mock_theory.md) помогает сравнивать геометрию.
[Исследовательские ограничения](tis_research_theory.md) объясняют, чего нельзя
заключать из одной картинки. [Общая методика](../Principes/testing_methodology.md)
задаёт порядок построения проверок.
