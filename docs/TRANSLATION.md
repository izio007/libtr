# Воспроизводимая трансляция документации

Единственные первоисточники математического содержания — `*_theory.txt` в этом каталоге.
`translate_docs.py` обрабатывает все эти файлы, создавая HTML и текстовые Live Editor `.m`.
Зависимость транслятора: Python 3.9 или новее, только стандартная библиотека.

## Изображения

Текстовые рисунки и псевдографика запрещены. Изображение задается отдельной строкой:

```text
[image: filter2win_trajectory.png]
```

Имя содержит только латинские буквы, цифры, дефис и подчеркивание, расширение `.png`.
Перед трансляцией PNG должен существовать в `runtime` и иметь сигнатуру PNG.
HTML содержит `<img src="../../runtime/filter2win_trajectory.png">`.
Live Editor содержит текстовую Markdown-ссылку на тот же снимок, а не встроенный
base64-вывод и не команды, имитирующие расчет графика.

Для filter2win снимки создает `generate_filter2win_doc_images` из каталога
`matlabtests`, выполняя существующий сценарий с фиксированным seed 1729.
Массивы, метрики и два PNG сохраняются в `runtime`. Этот каталог игнорируется Git:
после чистого клонирования изображения необходимо заново сгенерировать.

## Формулы

В `.txt` используются `$...$` и `$$...$$` с обычным LaTeX: один обратный слэш
у команды, два — у разделителя строк `cases`/матрицы. Нельзя копировать в источник
экранирование Live Editor или HTML-сущности вместо формульных разделителей.

Транслятор отделяет формулы от обычного текста и кода. В HTML применяются
разделители MathJax `\(...\)` и `\[...\]`; специальные HTML-символы кодируются,
обратные слэши LaTeX не удваиваются. MathJax 3.2.2 (SVG) хранится локально
в `html/assets`, поэтому рендеринг не зависит от CDN. Лицензия приложена.

Для Live Editor используется отдельное экранирование: формулы в `$...$`,
удвоение обратных слэшей, защита индексов и знаков сравнения по PlainTextPrincipe.
Код примеров не экранируется. Таблицы сохраняются как Markdown в `%[text]`.

## Запуск

1. В MATLAB добавить `matlabtests` в путь и вызвать `generate_filter2win_doc_images`.
2. Запустить `python docs/translate_docs.py` из корня репозитория.
3. Открыть HTML в браузере с разрешенным JavaScript, а `.m` — в Live Editor.

Транслятор отклоняет текстовые рисунки, некорректные маркеры, отсутствующие PNG,
незакрытые кодовые блоки и формульные разделители. Он не исправляет математику
автоматически: расхождения описания и реализации требуют отдельного рассмотрения.
