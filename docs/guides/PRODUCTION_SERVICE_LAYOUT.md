# Где находятся вычисления, испытания и служебные средства

| Назначение | Каталог |
|---|---|
| Вычислительные функции | [matlab/function](../../matlab/function/) |
| Физические модели и получение наблюдений | [matlab/engine](../../matlab/engine/) |
| Испытания и их данные | [matlab/tests](../../matlab/tests/) |
| Необязательный запуск через сервер | [tools/matlab](../../tools/matlab/) и [tools/pipeline](../../tools/pipeline/) |
| Преобразование документации | [tools/docs](../../tools/docs/) |

Вычислительные функции не зависят от испытаний, отчётов и рисунков.
Исходные наблюдения формируются отдельно от проверяемого оценивателя.
Случайные модели должны сохранять воспроизводимость и не вмешиваться
в чужую последовательность случайных чисел.

Обычный запуск выполняется из MATLAB; сервер не обязателен.
Команды находятся в одном [руководстве запуска](PIPELINE.md).
Экспорт документации выполняется отдельно и не запускает численные расчёты.
