# Аудит TXT-паспортов: исправления и математические развилки

Статус: частичное исправление разметки; математическая приемка заблокирована.
Основание: PaeroPrincipe.md, раздел 7 — неоднозначность паспорта выносится
Шефу до изменения метода. Ни код, ни исторические результаты не служат
основанием для подгонки формул.

## Выполнено без изменения метода

- Блочные формулы выделены на самостоятельные физические строки без маркеров
  списков; удалены хвостовые пробелы TXT.
- В формулы с дробями и суммами добавлен displaystyle согласно стандарту.
- Разделены склеенные заголовки mock; сигнатуры приведены к группировке индексов.
- Исправлены поврежденные обратные кавычки в описании отказа mock.
- Производные HTML и Live Editor перегенерированы, а не отредактированы вручную.

## Выявленные вопросы для согласования

| Паспорт | Место | Проблема и необходимое решение |
|---|---|---|
| lls | Раздел 4 | Вывод обязательного Bias-сжатия из одной строки с котангенсом не является выводом математического ожидания многопостовой оценки. Нужно заменить его исследовательской гипотезой либо дать вывод для определенной геометрии и распределения шума. |
| lls | Контракт ковариации | Отсутствует вывод ковариационного оператора; ранее выявлен реализованный сэндвич. Утвердить модель остатков до выбора эталона. |
| gn | Разделы 3–4 | Невзвешенный шаг и обратная J'J не определяют общий ковариационный контракт с приборными дисперсиями. Выбрать равноточную модель с явной дисперсией либо взвешенную постановку; сверить позиционер и ковариационное ядро. |
| gn | Разделы 5–6 | Дальность и малые элементы Якобиана объявлены достаточной причиной отказа; конкретные шаги и координата 874 км не снабжены воспроизводимым опытом. Критерий остановки назван, но не полностью определен. |
| gnp | Разделы 2–3 | Формулы используют r, определения — rho; порог epsilon_angle не определен. Унифицировать символы и согласовать численный контракт остановки. |
| gnp | Разделы 4–5 | Гарантия защиты мантиссы нормированным разворотом не доказана; ковариация не содержит модели дисперсий. Зенитная неопределенность смешана с обязательным бесконечным значением всех производных. |
| wlls | Раздел 1 | Угловой функционал смешан с весами линейных остатков. Требуется явно разделить пространства остатков. |
| wlls | Раздел 3 | Строго единичная ковариация нормированных остатков постулирована без вывода, при весах от случайной предварительной засечки. Ссылка на пункт 3.4 PaeroPrincipe отсутствует в действующем регламенте. Согласовать точную или приближенную модель ковариации. |
| wlls | Раздел 4 | Обязательное уменьшение Bias на 450 км не доказано для всех геометрий и шумов. Не использовать как условие теста. |
| mock | Раздел 1 | Двухстрочная матрица названа кососимметрической; необходимо различить оператор кросс-произведения и эквивалентные ограничения. Тождественная точность не оговорена рангом и конечной арифметикой. |
| mock | Разделы 2–3 | Однозначность осей противоречит последующей оговорке о знаках и кратности спектра. CRLB назван фактическим рассеянием без условий достижимости; дальность 450 км смешана с критерием обусловленности. |
| tis | Разделы 2–3 | Единичный вектор назван ортонормированным базисом; деление на cos(beta) объявлено устранением сингулярностей без условий применимости. |
| tis | Разделы 6–7 | Якобиан перехода назван ортогональным оператором; угловые компоненты полярной ковариации смешаны с линейными промахами. |
| tis | Раздел 8 | Осевые радиусы сечения эллипсоида и СКО проекций объявлены одной характеристикой; поворот ковариации назван дефектным. Согласовать смысл выходов tis_cov2std: сечения либо СКО. Порог 1e-3 м не обоснован. |
| filter2win | Разделы 1–3 | Правило малой доли аномалий допускает прием текущего выброса; не определены заполнение окон, накопленный прогноз и внешнее подтверждение маневра. Паспорт прямо фиксирует несовпадение модели с ядром. Выбрать утвержденную модель, а не переписать описание под код. |
| matmul3 | Разделы 1–6 | В прочитанном математическом контракте аналогичной развилки не найдено. Это не заменяет повторную сверку всех тестов и кода. |

## Граница приемки

Изменения алгоритмов, весов, ковариационных формул, зажимов и критериев остановки
в рамках редакционного исправления не выполнены. Необоснованные утверждения
не считаются доказанными даже при прохождении синтаксического шлюза.
Известный дефект отображения bmatrix в Live Editor требует отдельной проверки;
сохранность структуры при трансляции не означает успешный визуальный рендеринг.
