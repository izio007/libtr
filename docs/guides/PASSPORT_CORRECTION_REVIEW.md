# Открытые математические вопросы

Здесь сохраняются содержательные вопросы, выявленные при сверке теории
и исходников. Проверка оформления не является условием математической
приёмки. Понятный текст также не заменяет проверку формул и опыт.

| Область | Что требует отдельного решения |
|---|---|
| LLS | Уточнить модель ковариации при ошибках в коэффициентах линейных уравнений и связанном векторе свободных членов |
| WLLS | Оценить применимость приближения единичной ковариации нормированных остатков, когда веса рассчитаны по случайной предварительной точке |
| GN | Согласовать невзвешенную постановку шага с использованием взвешенной информационной матрицы в расчёте ковариации |
| GNP | Согласовать модель шума в ковариации, допуск остановки и обработку особенностей полярных координат |
| Геометрические преобразования | Обосновать численные ограничения у нулевой дальности и особых направлений; не смешивать их с физическими запретами |
| Оценки точности | Проверить соответствие подписей графиков: СКО проекции, радиус сечения и главная полуось — разные величины |

В основных теориях убраны безусловные утверждения о точном совпадении
расчётной ковариации с реальным разбросом, гарантированном выигрыше метода
и устранении ошибок одной заменой координат. Это исправление интерпретации,
а не изменение вычислительных алгоритмов.

Решение каждого вопроса требует выбранной модели, независимого ожидаемого
результата и подходящего опыта. Допуски не подгоняются под текущий ответ.
Проверки поведения и существующие математические испытания сохраняются.
