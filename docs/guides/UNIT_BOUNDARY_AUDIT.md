# Аудит граничного unit-контроля

## Проверенный промежуточный объем

`matlab/tests/unit_test_covariance_boundaries.m` вызывается без движка и сценарных
контекстов. Общий обнаружитель `unit_test_*.m` включает его автоматически.

- Пять ковариационных интерфейсов LLS/WLLS/GN/GNP/mock: недостаток постов
  возвращает status=1 и полную матрицу NaN размера 3x3.
- Те же пять интерфейсов: точная потеря ранга возвращает status=2 и NaN(3,3).
- LLS/WLLS: два противоположных азимута дают аналитическую нормальную матрицу
  diag(2*sin(t)^2,2*cos(t)^2,2). Проверены пять значений t=sqrt(c*eps),
  c=0.25,0.5,2,4,16, с обеих сторон используемого порога 2.2204e-16.
- Для успешных выходов проверяется вся матрица после диагонального масштабирования,
  а не только доминирующая компонента. Допуск нормы невязки: 1e-12.
- Всего 20 вызовов ядер. Ожидаемые отказы являются успешными утверждениями;
  неожиданные статусы, NaN или ошибки матрицы вызывают исключение теста.

Это аналитические проверки частного случая интерфейсов, не полная приемка методов.
Точка в точности на пороге не используется: округление тригонометрических функций
и сборки матрицы не позволяет задавать ее статус только исходным значением t.

## Блокеры полной прослеживаемости

1. docs/lls_theory.txt описывает позиционный оператор и Bias, но не содержит
   формулы реализованного в lls_covariance сэндвича с дальностной моделью шума.
2. docs/gn_theory.txt задает K=(J'J)^-1, тогда как gn_covariance вычисляет
   (J'WJ)^-1. Требуется решение по математическому контракту, не подгонка теста.
3. Ковариационные ядра LLS/WLLS/GN/GNP содержат нижние зажимы расстояний;
   их соответствие паспортам и поведение в зените требуют отдельной сверки.
4. Полное экстремальное покрытие позиционеров и сервисов не достигнуто.
   Существующие три проверки общего assert_position_contract недостаточны
   для заявления о полном покрытии этих методов.
