# Расчетные изображения сохраненных контекстов

Этап `png` TCP-конвейера вызывает `generate_context_test_images` из
`matlab/tests/`. Входы — `context_30km.mat` и `context_450km.mat` в каталоге
задания. При отсутствии контекстов конвейер создает их действующим генератором.
Имя 450km не означает замену дальности на 160 км: это отдельный контекст.

Для каждого контекста независимо вызываются LLS, WLLS, GN и GNP. Сохраняются
полная траектория и ансамбль в центральной точке (число реализаций из контекста).
Каждый из восьми PNG содержит траекторию, ошибку единичного решения,
облако центрального ансамбля с Bias и эмпирические полуоси. RMSE относится
только к центральному ансамблю, а не ко всей траектории.

Дополнительно unit-тесты `unit_test_cov2std(folder)` и
`unit_test_cov2std_3d(folder)` сохраняют PNG и MAT плоской и пространственной
сцен. Вызов без аргументов сохраняет проверку утверждений без экспорта.

`context_images.json` перечисляет десять PNG и результаты восьми расчетов.
`passed` означает отсутствие численных отказов и обнаруженных нарушений
контракта, но не выполнение неустановленного допуска точности. Большие Bias
и RMSE сохраняются в отчете. PNG проверяются через `imfinfo`.
Исходные массивы и отдельные результаты методов сохраняются в MAT.

Проверенный TCP-запуск: `runtime/pipeline/context_png_tcp_02/report.json`.
Этап прошел; сформированы десять дополнительных PNG, пять геометрических
PNG и два PNG filter2win. Восьмерка контекстных расчетов не дала отказов.
Это не полная приемка библиотеки или документов. Code Analyzer отдельного
прогона сообщил 4 и 9 замечаний к двум существующим тестам сечений;
полный визуальный аудит новых изображений не выполнен.

Исторический каталог `runtime/pipeline/tis_160km_all_01` не дополняется
задним числом. Все новые результаты находятся в отдельном задании.
