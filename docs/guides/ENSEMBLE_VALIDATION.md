# Проверка ансамблей ТИС

Контракт тестового контура, не новый метод оценивания координат.

Для N независимых реализаций одного положения x используются одинаковые входные
пеленги для сравниваемых методов, но результаты одного метода не передаются другому.
Внутренняя инициализация метода сохраняется. Шум аддитивный нормальный в радианах;
его дисперсии положительны и не обнуляются при бесшумной контрольной проверке.

Пусть n — число реализаций со status=0 и конечным вещественным выходом.
Среднее mu = sum(x_j)/n; Bias = mu-x; RMSE = sqrt(sum(||x_j-x||^2)/n).
Эмпирическая ковариация K = sum((x_j-mu)*(x_j-mu)')/(n-1).
При n<2 ковариация и спектр не определены. Все эти метрики условны по успешной
части ансамбля; failure_fraction = (N-n)/N публикуется всегда.
Согласованность проверяется равенством RMSE^2 = ||Bias||^2+(n-1)/n*trace(K).

Mock Delta = ||x_mock-x||, где x_mock получен отдельным вызовом mock_position
на идеальных пеленгах. Это не ошибка проверяемого оценивателя. Ковариационный
репер вызывается отдельно в истинной точке; равенство эмпирической ковариации
CRLB не предполагается для смещенных или нелинейных оценивателей.

Спектр K: K*V=V*S, V'*V=I; полуоси sqrt(diag(S)), углы atan2(V(2,:),V(1,:))
и atan2(V(3,:),hypot(V(1,:),V(2,:))). Знаки осей не фиксируют физический смысл.
matmul3 проверяется на реконструкции V*S*V' с независимым поэлементным эталоном.

Пять семейств: внутренняя область квадрата с изменением высоты; внешние квадранты
с координатами X до +160 км и отдельной точкой -180 км; два поста;
нулевая высота цели; повторные независимые измерения четырех
постов. Это восстановление состава испытаний, не воспроизведение исторических чисел.
Начальный воспроизводимый прогон: seed=1729, N=64, sigma=0.015 градуса.

Повторный прогон `tis_160km_all_01`: четыре координаты X=450000 заменены
на X=160000; отдельная точка X=-180000 сохранена. Ядра и критерии приемки
не изменены. Unit-набор: 11/11; ансамблевые случаи: 64/64; сформированы
пять PNG геометрий. Это результат указанной выборки, не гарантия отсутствия
отказов для любой геометрии на 160 км. Полный конвейер имеет статус FAILED:
документный контроль отклонил восемь паспортов, экспорт Live Editor заблокирован.
Отчет и расчетные данные: runtime/pipeline/tis_160km_all_01/.

Успех исполнения и успех утверждений разделяются: неожиданный отказ, status=0
с NaN/Inf, не-NaN аварийный выход или исключение — FAILED. Ожидаемый отказ
проверяется отдельным unit-тестом с заданным статусом и формой NaN-выхода.
В ансамбле нет автоматического разрешения отказов только потому, что дальность велика.
Числа, статусы, исключения и изображения сохраняются до финального assert.

Проверки не означают полного покрытия всех паспортов: отдельно остаются аудит
порогов GN/GNP/WLLS, статистическая сходимость при увеличении N и документный барьер.
