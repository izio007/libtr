# Единая конфигурация траекторных сценариев

Параметры ближнего и дальнего интеграционных сценариев определяются в
`matlabtests/tis_trajectory_scenarios.m`. Для изменения рубежа меняется только
`near.Trajectory.Y_center_true` либо `far.Trajectory.Y_center_true` (метры).
Остальные параметры сценария при этом остаются прежними.

`tis_context_filename` получает имя `context_<дальность в км>km.mat` из
конфигурации. Генератор контекстов, проверка наличия файлов в конвейере и
генератор изображений используют эту функцию. Имена выходных PNG и MAT
генератора изображений наследуют ту же метку.

Новые траекторные MAT-файлы содержат одну переменную `cfg`.
Загрузчик поддерживает также старые файлы с единственной переменной:
ее имя и имя файла не влияют на выбор расчетной логики.
Диспетчер различает траекторию (`Points`) и полигон (`RangeSteps`) по схеме.
Неизвестная схема отклоняется вместо молчаливого выбора полигона.

Инициализатор `service_init_geometry_trajectory` получает число точек,
высотный профиль, шум и seed из конфигурации. Старые именные инициализаторы
остаются обертками; они не содержат значений дальности или отдельных алгоритмов.
Неявные переопределения шума, высоты и числа реализаций устранены.
Состояние RNG вызывающего процесса восстанавливается.

Ранее сохраненные результаты не перезаписываются автоматически. После
изменения параметров следует создавать новый каталог расчетного задания.
Файлы разных сценариев с одинаковой дальностью следует размещать в разных
каталогах, поскольку текущая маска имени определяется дальностью.

Проверка: `unit_test_context_configuration` проверяет оба семейства,
другие дальности, дробную метку, независимость от имени файла и оберток,
параметры шума, высоты, числа точек и сохранение RNG.
`unit_test_pipeline` проверяет создание среды после изменения формата.
