# Document gate: PlainTextPrincipe 5.21

All repository paths below are relative to the repository root.

The JSON Lines endpoint accepts action `documents`. Actions `liveeditor` and
`all` run this gate before exporting Live Editor files. On gate failure,
export is blocked and the job fails; independent preceding stages retain
their own results. Restart the endpoint to load changed MATLAB functions.

Request:
```json
{"v":1,"op":"submit","id":"documents_review_01","action":"documents"}
```

`runtime/pipeline/<id>/documents_results.json` contains per-document errors
and static metrics. The gate checks source formula delimiters, named commands
against the 5.21 profile, supported environments, PNG readability, generated
formula counts, and preservation of matrix row/column separators in Live Editor.
It reports the first failure per document and continues with other documents.

This is a static gate, not full acceptance. Browser MathJax execution, the
rendered formula count, and the approved 2–3-page visual audit remain pending.
Source-to-output content equivalence and all serialization rules are not yet
exhaustively checked. `passed` means the implemented stage checks passed,
not that the documentation has received visual approval.

The current eight passports fail the closed command profile (examples: vec,
in, dots, times, lambda). The gate intentionally does not enlarge that profile
or rewrite mathematics. Profile extensions require approval and regression
examples. Production documents have not been regenerated by this change.

The translator now preserves bmatrix instead of flattening it. Rendering this
representation still requires Live Editor verification after profile compliance.
