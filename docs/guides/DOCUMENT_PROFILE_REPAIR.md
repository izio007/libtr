# Исправление разбора профиля 5.23

Парсер `matlabengine/service_parse_document_profile.m` читает только пункт 9,
ограниченный следующим пунктом 10. Он проверяет имена всех шести категорий,
отклоняет неизвестные, пустые, повторные и отсутствующие категории. Список
команд извлекается из стандарта, а не дублируется в коде. Поддерживаются LF,
CRLF и CR. Посторонние списки вне пункта 9 не влияют на профиль.

Регрессия: `matlabtests/unit_test_document_profile.m`. Проверяется актуальный
стандарт, варианты окончаний строк, посторонний список, отрицательные случаи,
положительный минимальный паспорт и запрет неизвестной команды.

TCP-запуск `runtime/pipeline/document_parser_fix_01` обработал все восемь
паспортов без фатального отказа парсера. Два паспорта прошли, шесть отклонены:

| Паспорт | Первое обнаруженное нарушение |
|---|---|
| filter2win | `vert` вне профиля, строка 8 |
| gn | Потеря структуры матрицы, формула 44 |
| gnp | `vert` вне профиля, строка 48 |
| matmul3 | `operatorname` вне единственного разрешенного исключения, строка 78 |
| mock | `psi` вне профиля, строка 40 |
| tis | `delta` вне профиля, строка 87 |

Это первые ошибки каждого паспорта, не исчерпывающий перечень. Утвержденный
профиль не расширен и контроль не ослаблен ради зеленого статуса. Приемка
документного пакета остается заблокированной до согласования профиля с
математическими паспортами и восстановления производных представлений.

Артефакт `для$arg` не найден в отслеживаемых файлах и PowerShell-скриптах
каталогов tools и runtime. Ошибочный разовый вызов не повторялся; проверки
выполнены через существующий TCP-клиент без вставки MATLAB-кода в PowerShell.
