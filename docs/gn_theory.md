# Уточнение координат методом Гаусса — Ньютона — GN

## Зачем нужен метод

Линейная засечка сравнивает расстояния до прямых. Этот метод сравнивает сами
углы: для предполагаемой точки рассчитывает, что должны видеть посты,
и последовательно изменяет координаты, уменьшая расхождение с измерением.

Нужны координаты постов, углы и начальная оценка положения. Результат —
уточнённая точка в метрах. Углы измеряются в радианах. Сходимость локальна:
плохое начальное приближение может привести к отказу или другому решению.
Матрица Якоби ниже — таблица чувствительности каждого угла к каждой кокоординате.


## 1. Геометрия наблюдения
Положение цели в локальных осях «восток — север — вверх» задаётся вектором:

```math
\mathbf{X}=[x,y,z]^T \in \mathbb{R}^3
```

Измерительная сеть состоит из $`M`$ наземных базовых постов с известными, статичными декартовыми координатами:

```math
\mathbf{X}_{si}=[x_{si},y_{si},z_{si}]^T,\quad i=1,\dots,M
```

Для каждого поста ТИС вектор дальности (прямой визирный луч «пост $`\rightarrow`$ цель») задается пространственными приращениями в метрах:

```math
\Delta x_i = x - x_{si}, \quad \Delta y_i = y - y_{si}, \quad \Delta z_i = z - z_{si}
```

Продольная дальность до цели в горизонтальной проекции $`XOY`$ и полная пространственная дальность до $`i`$-го поста равны соответственно:

```math
r_{xy,i}=\sqrt{\Delta x_i^2+\Delta y_i^2}, \quad r_i = \Vert\mathbf{\Delta X}_i\Vert = \sqrt{\Delta x_i^2+\Delta y_i^2+\Delta z_i^2}
```

Аппаратура каждого поста ТИС измеряет угловое направление на цель (вектор пеленгации) от горизонтальной оси $`OX`$ декартовой земли против движения часовой стрелки в соответствии со строгим тригонометрическим законом нелинейного отображения $`\mathbf{\Psi}(\mathbf{X})`$:

* Прогнозный азимут ($`\alpha_{pred,i}`$):

```math
\alpha_{pred,i}(\mathbf{X}) = \text{atan2}(\Delta y_i,\Delta x_i) = \text{atan2}(y - y_{si}, \ x - x_{si})
```

* Прогнозный угол места ($`\beta_{pred,i}`$):

```math
\beta_{pred,i}(\mathbf{X}) = \text{atan2}(\Delta z_i, r_{xy,i}) = \text{atan2}\left(z - z_{si}, \ \sqrt{(x - x_{si})^2 + (y - y_{si})^2}\right)
```

## 2. Производные углов по координатам ($`J_{\text{cart}}`$)
Классический нелинейный метод Гаусса-Ньютона требует вычисления частных производных измерительных функций $`\alpha_{pred,i}`$ и $`\beta_{pred,i}`$ по оцениваемому декартову вектору состояния $`\mathbf{X} = [x, y, z]^T`$. Матрица Якоби $`J_{\text{cart}} \in \mathbb{R}^{2M \times 3}`$ формируется построчно через базовые правила дифференцирования.
## 2.1. Производные азимута (Азимут $`\alpha_{pred,i}`$)
Используя табличную производную функции $`\text{atan2}(y,x)`$, где $`\frac{\partial \text{atan2}(y,x)}{\partial x} = -\frac{y}{x^2+y^2}`$ и $`\frac{\partial \text{atan2}(y,x)}{\partial y} = \frac{x}{x^2+y^2}`$, дифференцируем по декартовым осям:

   1. Дифференцирование по кокоординате $`x`$:

```math
J_{\text{cart}}(2i-1, 1) = \frac{\partial \alpha_{pred,i}}{\partial x} = -\frac{\Delta y_i}{\Delta x_i^2 + \Delta y_i^2} = -\frac{\Delta y_i}{r_{xy,i}^2} \quad \left[\frac{\text{рад}}{\text{метр}}\right]
```

   2. Дифференцирование по координате $`y`$:

```math
J_{\text{cart}}(2i-1, 2) = \frac{\partial \alpha_{pred,i}}{\partial y} = \frac{\Delta x_i}{\Delta x_i^2 + \Delta y_i^2} = \frac{\Delta x_i}{r_{xy,i}^2} \quad \left[\frac{\text{рад}}{\text{метр}}\right]
```

   3. Дифференцирование по координате $`z`$:
   Поскольку функция азимута инвариантна к высоте цели:

```math
J_{\text{cart}}(2i-1, 3) = \frac{\partial \alpha_{pred,i}}{\partial z} = 0 \quad \left[\frac{\text{рад}}{\text{метр}}\right]
```

## 2.2. Производные угла места (Угол места $`\beta_{pred,i}`$)
Применяя дифференцирование сложной функции к $`\beta_{pred,i} = \text{atan2}(\Delta z_i, r_{xy,i})`$, учитываем, что полная пространственная дальность $`r_i^2 = r_{xy,i}^2 + \Delta z_i^2`$.

   1. Дифференцирование по кокоординате $`x`$:

```math
J_{\text{cart}}(2i, 1) = \frac{\partial \beta_{pred,i}}{\partial x} = \frac{\partial \text{atan2}(\Delta z_i, r_{xy,i})}{\partial r_{xy,i}} \cdot \frac{\partial r_{xy,i}}{\partial x} = \left(-\frac{\Delta z_i}{r_i^2}\right) \cdot \frac{\Delta x_i}{r_{xy,i}} = -\frac{\Delta x_i \Delta z_i}{r_i^2 \cdot r_{xy,i}} \quad \left[\frac{\text{рад}}{\text{метр}}\right]
```

   2. Дифференцирование по координате $`y`$:

```math
J_{\text{cart}}(2i, 2) = \frac{\partial \beta_{pred,i}}{\partial y} = \frac{\partial \text{atan2}(\Delta z_i, r_{xy,i})}{\partial r_{xy,i}} \cdot \frac{\partial r_{xy,i}}{\partial y} = \left(-\frac{\Delta z_i}{r_i^2}\right) \cdot \frac{\Delta y_i}{r_{xy,i}} = -\frac{\Delta y_i \Delta z_i}{r_i^2 \cdot r_{xy,i}} \quad \left[\frac{\text{рад}}{\text{метр}}\right]
```

   3. Дифференцирование по координате $`z`$:

```math
J_{\text{cart}}(2i, 3) = \frac{\partial \beta_{pred,i}}{\partial z} = \frac{r_{xy,i}}{\Delta z_i^2 + r_{xy,i}^2} = \frac{r_{xy,i}}{r_i^2} \quad \left[\frac{\text{рад}}{\text{метр}}\right]
```

## 3. Последовательное уточнение точки
На каждом шаге приближённо минимизируется сумма квадратов угловых остатков. Остаток — измеренный угол минус угол, рассчитанный для текущей точки:

```math
(J_{\text{cart}}^T \cdot J_{\text{cart}}) \cdot \Delta \mathbf{X} = J_{\text{cart}}^T \cdot \mathbf{residual}
```

Где на каждом $`k`$-м шаге уточнения вектор угловых остаточных невязок $`\mathbf{residual} \in \mathbb{R}^{2M \times 1}`$ принудительно приводится к главному тригонометрическому интервалу $`[-\pi; \pi]`$:

```math
\mathbf{residual} = \begin{bmatrix} \alpha_1 - \alpha_{pred,1}(\mathbf{X}^{(k)}) \\ \beta_1 - \beta_{pred,1}(\mathbf{X}^{(k)}) \\ \vdots \\ \alpha_M - \alpha_{pred,M}(\mathbf{X}^{(k)}) \\ \beta_M - \beta_{pred,M}(\mathbf{X}^{(k)}) \end{bmatrix}
```

Вычисление линейного декартова вектора шага поправок $`\Delta \mathbf{X} = [\Delta x, \Delta y, \Delta z]^T`$ (в метрах) выполняется :

```math
\Delta \mathbf{X} = (J_{\text{cart}}^T \cdot J_{\text{cart}})^{-1} \cdot J_{\text{cart}}^T \cdot \mathbf{residual}
```

```math
\mathbf{X}^{(k+1)} = \mathbf{X}^{(k)} + \Delta \mathbf{X}
```

Малое изменение расчётных углов служит условием остановки. Оно не доказывает глобального минимума. Недостаточный ранг производных означает, что по выбранным наблюдениям поправка не определяется однозначно.

## 4. Разброс оценки и ограничения

Для равноточных независимых угловых ошибок с дисперсией $`\sigma^2`$
линейное приближение ковариации в найденной точке имеет вид

```math
K_{\rm lin}=\sigma^2(J^TJ)^{-1}.
```

При единичной дисперсии получается обратная матрица $`J^TJ`$ из исходного
описания. Для неравных или коррелированных ошибок с ковариацией $`\Sigma`$
невзвешенному шагу соответствует другая формула:

```math
A=(J^TJ)^{-1}J^T,\qquad K_{\rm lin}=A\Sigma A^T.
```

Обратная матрица $`(J^T\Sigma^{-1}J)^{-1}`$ относится к взвешенной постановке.
В текущем расчёте ковариации используется именно взвешенная информационная
матрица. Это ранее выявленное расхождение с невзвешенным описанием шага;
редактура документа не меняет алгоритм и не объявляет вопрос решённым.
См. [перечень математических вопросов](guides/PASSPORT_CORRECTION_REVIEW.md).

В точке над постом горизонтальная дальность равна нулю и азимут не определён.
Вблизи этой особенности производные чувствительны к ошибкам. Почти параллельные
направления плохо определяют дальность. Конечность результата и остановка
итераций сами по себе не гарантируют требуемую точность.

## 5. Независимые проверки

Проверяются точные направления, аналитические производные, граница периода
азимута, зависимость от начальной точки, отказ при недостаточной геометрии.
Для шумовых опытов отдельно учитываются смещение, разброс и доля отказов.
