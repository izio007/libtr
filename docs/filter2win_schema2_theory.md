# Двухоконный фильтр: прежняя схема 2

## Назначение и отличие

Эта схема сохраняется для совместимости. Для нового поведения с двумя
сохраняемыми группами используется [основное описание filter2win](filter2win_theory.md).
В схеме 2 история может удаляться по времени и при длительном разрыве;
перенос альтернативы заменяет основную базу. Эти правила нельзя переносить
на схему 3, где обе группы сохраняются.

На входе — скалярная координата, время в секундах и признак пропуска.
Времена строго возрастают. Истинная координата и названия этапов опыта
фильтру неизвестны. Длительная согласованная ошибка может быть принята
за новую группу.

## Модель одной группы — F2W-S2-02

Для неподвижной цели скорость равна нулю. При известной скорости используется
заданное значение. В линейной модели скорость оценивается медианой попарных
наклонов; слишком близкие по времени пары исключаются.

```math
v=\mathop{\mathrm{median}}\limits_{i<j}
\frac{x_j-x_i}{t_j-t_i},\qquad
q_i=x_i-v(t_i-t_n),\qquad
a=\mathop{\mathrm{median}}\limits_i q_i,\qquad
\widehat x(t)=a+v(t-t_n).
```

Медиана чётного числа значений — полусумма двух центральных. Разброс оценивается
медианой абсолютных отклонений от уровня. Дополнительно может исключаться
заданная доля крайних остатков с каждой стороны; хотя бы один сохраняется.

Окрестность модели задаётся отдельно снизу и сверху. Она может расширяться
с разбросом и возрастом последнего наблюдения. Разные границы приёма и
удержания уменьшают частые переключения около порога. Качество дополнительно
ограничивается размахом, модулем скорости и остатками без возрастного расширения.

## История и готовность — F2W-S2-03

Хранятся только реальные конечные пары. Прогноз не увеличивает число наблюдений.
Точки строго старше заданного срока удаляются; равенство временной границе
сохраняется. Длительный разрыв может очистить основную группу, а для
альтернативной действие задаётся отдельно.

Готовность требует одновременно достаточного числа точек, достаточного
интервала между принятыми временами, допустимых внутренних разрывов
и качества. Много точек за короткое время не заменяет требуемую длительность.

## Альтернативная группа и переход — F2W-S2-04/05

Согласованность альтернативы проверяется по окрестности медианы, ближайшему
соседу либо усечённому размаху. Перенос дополнительно требует общего качества
группы. Несовместимая точка может быть проигнорирована, начать накопление заново
или очистить альтернативу — согласно выбранной настройке.

Игнорируемая точка не подтверждает группу. Для полного либо разрешённого
частичного накопления отдельно учитываются число подтверждений, реальные
времена, свежесть и разрывы. Может применяться относительное ограничение
разброса альтернативы по отношению к основной группе.

Сроки выдачи при пропуске и при отклонении наблюдения настраиваются независимо.
Нулевой срок отключает соответствующее продолжение выдачи. Полный сброс
определяется возрастом последнего конечного входа.

Переключение может иметь ожидание и плавный переход. Для доли пройденного
времени $`u\in[0,1]`$ вес новой модели задаётся линейно либо гладкой функцией:

```math
w(u)=u\quad\hbox{или}\quad w(u)=u^2(3-2u).
```

Поведение при пропуске и возврате к основной группе задаётся заранее.
После переноса может требоваться стабилизация: одновременно заданное
время и число новых реальных точек.

## Отказы и проверяемые требования

Ошибка входа оставляет прежнее состояние. Выполненный шаг может дать
недоступный выход: это отличается от ошибки вычисления. Изменение настроек
требует новой истории. Все параметры задаются до соответствующего опыта.

| Обозначение | Предмет проверки |
|---|---|
| F2W-S2-01 | Происхождение прежней схемы; история интеграции сохраняется в Git |
| F2W-S2-02 | Медиана, попарные наклоны, разброс и временная опора |
| F2W-S2-03 | Порядок хранения, вытеснение и временная граница |
| F2W-S2-04/05 | Готовность, переходы и неизменность состояния при отказе |
| F2W-S2-06 | Поведение на заданной последовательности наблюдений |
| F2W-S2-07 | Согласованность демонстрации с рассчитанными данными |
| F2W-S2-09 | Граничные режимы, частичное накопление, перенос начала времени и координат |

Программные имена параметров и статусы находятся в
[исходнике](../matlab/function/filter2win.m), проверочные последовательности —
в [общем файле данных](../matlab/tests/configs/filter2win_test_cases.json).
Покрытие отдельных режимов не доказывает проверку всех сочетаний настроек.
