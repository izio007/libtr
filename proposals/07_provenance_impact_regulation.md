структуры проекта, подобное idea, для последующей практической реализации.

## Область изменений и проверки

Изменяются только новый каталог и реестр proposals. Проверяются UTF-8,
локальные ссылки, уникальность REQ-якорей и git diff --check.
MATLAB, математические паспорта, транслятор и экспорт не затронуты;
их проверки не входят в данную задачу. Пользовательские изменения корневых
регламентов и расчетные файлы не включаются в коммит.

Идентификатор коммита определяется через git log -- proposals/07_provenance_impact_regulation.md.
