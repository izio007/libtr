## Ещё не выполнено

Полный реальный сценарий и массовый GPU-профиль остаются отдельной задачей.
Она не входит автоматически в обычные проверки или универсальный Code Freeze.
Технические условия сохранены в matlab/tests/gpu_execution_contract.md:

- Независимые реализации можно распараллеливать; такты алгоритма с памятью
  сохраняют причинный порядок. Числа — double, RNG-контекст — явный.
- Пакет делится по памяти GPU; данные сохраняются на устройстве между расчётами.
- Выбранный GPU-режим не заменяется незаметно CPU при ошибке или нехватке ресурсов.
- Сравнение с независимым CPU-репером использует те же наблюдения и допуски.
- Ускорение оценивается по полному времени реального сценария, включая передачи.

При возобновлении этой задачи сначала выбирается реальная нагрузка. Выпуск
документов, отдельная приёмка и новый регламент для запуска не требуются.
