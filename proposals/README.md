# Предложения по развитию libtr

Каталог перспективных предложений для Главного аналитика. Предложения не
являются действующими регламентами, математическими паспортами или разрешением
на реализацию. После согласования математическое описание метода оформляется
в docs/ согласно PaeroPrincipe.md; производные представления создаются транслятором.

## Нумерация

- Одно предложение — один Markdown-файл с префиксом 01_, 02_, …, 99_.
- Следующий номер — следующий после наибольшего выделенного номера.
- Номера не переиспользуются и не меняются при изменении статуса предложения.
- Отклоненные и реализованные предложения сохраняются со своим статусом.
- После 99 требуется согласовать расширение нумерации, а не начинать ее заново.
