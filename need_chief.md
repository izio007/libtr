## F2W-HOST-01. Новый изолированный сервер для приёмки архива

Уточнение текущего препятствия: attempt02/05/06/07 имеют MATLAB PASS,
но new_server=false. Старый отказ Editor ниже — история; повторный запуск
на прежнем host не решает вопрос нового процесса. Требуется только решение
режима замены/изоляции, а не повторное разрешение исправлять экспорт.

Актуальная попытка 0.2.0: существующий PID 17328 выполнил расчётные checks
из распаковки с изолированным path, но PDF export завершился ошибкой
Unable to open or load the Editor. Требуется рабочий Editor и согласованный
режим нового процесса; старые сведения PID ниже относятся к первой попытке.
Отчёт: runtime/pipeline/0b41ee6b73374de59c1ccb5d32f84f78/report.json.

Команда Шефа: новый MATLAB-сервер без штатных путей проекта. При обследовании
02.10.2026 :5555 занят постоянным host PID 28860, старт 01.10.2026 09:37:17,
запущенным через tools/matlab/tcpserver5555.m. Процесс не изменялся.
Регламент требует единственный постоянный сервер и его сохранение.
- [ ] Разрешить контролируемую замену этого host на новый из распакованного
  пакета после проверки живой очереди и отсутствия активного задания либо
  согласовать другой режим изолированной приёмки. Второй порт не используется
  как молчаливое исключение из регламента. Отсутствие queued/running в файлах
  отчётов не является доказательством пустой живой очереди.
Текущие reset/run вызывают setup_test_paths проекта, поэтому перезапуск
существующего bootstrap не докажет автономность. Остаток — F2W-PACK-01.

## ICD-01. Исходные требования первого профиля обмена

Основание: открытые решения раздела 9 IcdPrincipe.md; работа — ICD-01
в need_work.md. Привязка к коммиту постановки — история этих файлов.

- [ ] Указать первый целевой объект/состав участников и обязательные каналы,
  платформы, ПИВ или другие исходные спецификации, если они уже определены.
- [ ] Для команд и событий определить допустимую задержку и требуемую безопасную

  требование. Правило 3T для периодических параметров повторно не согласуется.
